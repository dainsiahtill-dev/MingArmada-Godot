# 货栈门面模块

资源ID：`building-warehouse-front` · 建筑与构件 · P0

原生产预算模块；为命名建筑及场景装配提供可复用构件。

## 视觉与结构

单层木梁柱与砖石/灰泥填墙的货栈大开间门面，建议宽4—6米、高3—4米；低石基、无遮蔽货门洞、朴素檐口，1621澳门及后续福建仓储使用；独立门扇另引。

## 制作与复用

原83基模预算内1项，沿用 building-warehouse-front；目标交付3级LOD。现有仅程序式ArrayMesh/数据源 modules/scene_engine/assets/coastal_detail_library.gd，没有独立环境GLB，不当作已完成模型。 同拓扑材质、尺度与节点显隐不增基模；独立新拓扑须调整预算。

创作概念；地点与年代沿当前剧本，未取得当时原始建筑平面、立面与构造档案，不是精确历史复原。所有建议尺寸是制作尺度。

此目录是生产参考，不被Godot自动导入。需要运行时使用时另行经现有资产合同导出。
