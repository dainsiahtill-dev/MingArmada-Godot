# 港市摊棚

资源ID：`coastal-market-stall` · 沿海设施 · P0

原生产预算模块；为命名建筑及场景装配提供可复用构件。

## 视觉与结构

四柱轻型木摊与布棚，建议2—3米见方、高2—2.5米；旧粗布、木托台、可收起遮棚；1620—1630年代港市换粮药与招募使用，货物单独引用。

## 制作与复用

原83基模预算内1项，沿用 market-stall；目标交付3级LOD。现有仅程序式ArrayMesh/数据源 modules/scene_engine/assets/coastal_detail_library.gd，没有独立环境GLB，不当作已完成模型。 同拓扑材质、尺度与节点显隐不增基模；独立新拓扑须调整预算。

创作概念；地点与年代沿当前剧本，未取得当时原始建筑平面、立面与构造档案，不是精确历史复原。所有建议尺寸是制作尺度。

此目录是生产参考，不被Godot自动导入。需要运行时使用时另行经现有资产合同导出。
