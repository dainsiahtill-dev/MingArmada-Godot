# 区域棕榈树

资源ID：`nature-palm` · 自然与材质条件 · P2

原生产预算模块；为命名建筑及场景装配提供可复用构件。

## 视觉与结构

可选区域棕榈形态，建议4—8米高，环痕干与少量叶簇，限有明确地域审查的沿岸点位；不能把无风海面一场推成热带全域。

## 制作与复用

原83基模预算内1项，沿用 nature-palm；目标交付3级LOD。现有仅程序式ArrayMesh/数据源 modules/scene_engine/assets/vegetation_library.gd、assets/reference/vegetation-geometry.json，没有独立环境GLB，不当作已完成模型。 同拓扑材质、尺度与节点显隐不增基模；独立新拓扑须调整预算。

现代创作生态概念；未作历史植被或具体树种鉴定，不宣称某地点17世纪植物分布已考证。建议尺寸是制作尺度。

此目录是生产参考，不被Godot自动导入。需要运行时使用时另行经现有资产合同导出。
