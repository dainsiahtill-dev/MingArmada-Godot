# 内岸草土地表材质集

资源ID：`nature-ground-materials` · 自然与材质条件 · P1

岛岸后层、港巷边缘与宅院外部的地表过渡；与独立草簇和灌木区分。

## 视觉与结构

草土、林下暗土与碎石路的低密度组合，通行区域保持平整可读；避免热带密林覆盖全部福建/平户港口，具体生态待地域审查。

## 制作与复用

地表材质/贴图与散布配置，独立基模0；草簇、灌木仍只引用原6自然基模。
