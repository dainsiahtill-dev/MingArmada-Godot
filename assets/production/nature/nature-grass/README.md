# 岸边草簇

资源ID：`nature-grass` · 自然与材质条件 · P0

原生产预算模块；为命名建筑及场景装配提供可复用构件。

## 视觉与结构

建议0.15—0.8米高的岸草簇，多方向窄叶、根部聚合；沙岸干湿线以上使用，不以全地面高密草铺满港口通道。

## 制作与复用

原83基模预算内1项，沿用 nature-grass；目标交付3级LOD。现有仅程序式ArrayMesh/数据源 modules/scene_engine/assets/coastal_detail_library.gd，没有独立环境GLB，不当作已完成模型。 同拓扑材质、尺度与节点显隐不增基模；独立新拓扑须调整预算。

现代创作生态概念；未作历史植被或具体树种鉴定，不宣称某地点17世纪植物分布已考证。建议尺寸是制作尺度。

此目录是生产参考，不被Godot自动导入。需要运行时使用时另行经现有资产合同导出。
