# 岸线干湿石砂材质集

资源ID：`nature-shore-materials` · 自然与材质条件 · P0

石堤、沙滩、岩岸与近岸浅区的共享材料目标，避免不同港口重复生产相同基础表面。

## 视觉与结构

砂、湿砂、干岩、湿岩和潮水线的低频颜色/粗糙度差异；重复尺度按人/船比对，细节不抢战术可读性；纹理并非独立几何。

## 制作与复用

材质/纹理原件，独立基模0；复用到coastal-stone-step与nature-rock等，不另算每港材质为模型。

自然表面艺术概念；不构成任一港口历史材料取样或考古证据。
