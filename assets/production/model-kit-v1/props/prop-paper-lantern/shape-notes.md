# prop-paper-lantern 形制与审查

H/C级早江户一般灯具设计，不与防风船灯混为同一几何。

纸面、竹圈、提点与修补处可读；形制未得田川家直接证据，仍为旧剧情/家居候选。

本项为模型前期创作候选，史实与建模均未批准。详见 [建筑器物研究](../../../../../docs/production/model-preproduction-2026-10-24/research-environment-props.md) 与 [补充说明](../../../../../docs/production/model-preproduction-2026-10-24/research-clarifications.md)。
