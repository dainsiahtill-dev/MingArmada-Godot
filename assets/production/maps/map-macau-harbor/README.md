# 澳门货栈与接驳泊区差异包

资源ID：`map-macau-harbor` · 场景与地图 · P0

第一幕港口工作区，与货栈、旧铺和夜航出港共用，提供装货至离岸的小范围路线。

## 视觉与结构

1621—约1623，有限石岸/木码头、华商货栈与外泊大船方向；步行区域建议几十米级，夜间岸灯用于离岸辨向，远城只做低干扰背景。
