# 铁料货组

资源ID：`prop-iron-stock` · 道具与货物 · P0

六货种中的铁料，货舱与市场必须具备与粮、瓷、布不同的轮廓。

## 视觉与结构

少量朴素铁块／条坯、粗锻表面、绳捆或木托，体量可搬；避免现代钢卷、螺纹钢和工业标准锭标。

## 制作与复用

一套简单铁料模块，图标与货舱共用；不衍生未经系统需要的矿石／冶炼工艺链。

已有原创铁料PNG；具体明末铁料贸易形态待审，属于既有商品系统需求。

此目录是生产参考，不被Godot自动导入。需要运行时使用时另行经现有资产合同导出。
