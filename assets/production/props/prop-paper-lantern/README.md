# 平户手糊纸灯

资源ID：`prop-paper-lantern` · 道具与货物 · P1

两人共同弄坏又补好的灯，表现成家选择；不同于船灯。

## 视觉与结构

轻竹架、薄纸罩、明显补纸一角与提拿点；轮廓克制，双手护灯点清楚，不用现代节庆塑料灯或宫灯大穗。

## 制作与复用

独立纸灯软罩与竹架节点；与船灯共用光色但不同形体，不能简单换材质完成。

needs-concept；原创亲情物件，平户具体灯制尚需地方史料审查。
