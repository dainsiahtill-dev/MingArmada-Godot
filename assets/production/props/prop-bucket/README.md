# 提水小桶

资源ID：`prop-bucket` · 道具与货物 · P0

堵漏、救火和生活提水；体量与淡水储桶不同。

## 视觉与结构

直壁或稍收底木桶、弧形提梁、桶口可见；单手握点与倒水转轴清楚，不用现代塑料或镀锌铁桶。

## 制作与复用

独立小桶基模；水面为共享平面／效果，不为每个水量增加模型。

needs-concept；救火补漏系统需要，具体提梁形式为设计方案。

此目录是生产参考，不被Godot自动导入。需要运行时使用时另行经现有资产合同导出。
