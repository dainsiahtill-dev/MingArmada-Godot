## 视觉与结构

柔软长方布包或卷布、外层包布、绳扎与小封记；货包体量以双手抬抱为准，留可拆封处。

## 制作与复用

一个布包主体加可替换布卷节点；折叠旧衣可复用软布布局或角色服装，不额外制造每种花纹基模。
