# 米粮袋

资源ID：`prop-grain-sack` · 道具与货物 · P0

米粮、船员口粮与劫粮剧情共用的软货容器。

## 视觉与结构

粗布鼓袋、扎口与底部压褶，袋身重心低；少量米粒可作可见节点，载货与手持有清楚抓点。

## 制作与复用

独立粮袋基模；同型香料袋复用本主体和标记，不按粮种与库存量建新模。
