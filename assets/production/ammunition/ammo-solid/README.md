# 实心炮弹

资源ID：`ammo-solid` · 弹药外观 · P0

三种现有海战弹药中的实心弹，兼作甲板弹架与UI物品。

## 视觉与结构

单枚深色金属球、局部旧化；可成小堆与木托组合，按炮与手掌比例核查。

## 制作与复用

单件模块重复实例化；UI由合格模型正交渲染或复验现有PNG。弹药与炮身、炮架分别交付。

既有游戏设计；实心弹为时代通用形体，链弹／葡萄弹未核得本剧每场具体使用记录，history-notes不得写成确证史实。

此目录是生产参考，不被Godot自动导入。需要运行时使用时另行经现有资产合同导出。
