# 鸟铳与长火绳枪

资源ID：`firearm-matchlock` · 个人火器 · P1

补足炮与个人火器的区分；吕宋脱险、米船伏击等枪声所需的持用形体。剧本未逐支标明枪种。

## 视觉与结构

长细钢铁管搭配木托，侧面火绳夹轮廓清楚，肩托形式按同代区域样本审查；双手、背带和腰侧火绳为角色挂点。禁止燧发机构、雷管、现代导轨及后世清代豪华御用样式。

## 制作与复用

一个长火绳枪主体先覆盖区域普通兵员；日本／欧洲差异先由木托配件审查，若轮廓和手位不同才加新主体。不能复用炮身或把长枪缩为手枪。
