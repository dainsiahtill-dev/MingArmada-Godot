## 视觉与结构

低矮厚木侧板、横梁和木轮，铁件朴素；炮耳座、轮轴、甲板系索点分明；完整与断轴节点可切换。先按炮手和甲板比例审查，不输出工程尺寸。

## 制作与复用

独立炮架基模；轻重炮可在核准范围内形变，不适配时再增基模。旧福船GLB内cannon节点是组合件，只供提取评估；坏轴不能只变色。

needs-concept；剧本轮轴明确，轮式架形式可用；并非所有中国炮或佛朗机均放这种架。
