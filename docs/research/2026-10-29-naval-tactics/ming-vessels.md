# 明清及传统船型：史料分类与玩法职责

- 研究子题：`naval-tactics-20261029-ming-vessels`。
- 日期：2026-10-29。
- 状态：资料研究；未建模、未实现 Demo、未运行游戏，未取得动态或性能证据。
- 范围：船名、形态、水域与用途的来源核查；最后一栏均为原创玩法提案。此笔记不是已经登记、验证的算法论文。

## 分类先行

建议将“地区船体传统 / 具体型式或号级 / 推进方式 / 作战装具与任务”分开记录。同一条船可以同时属于福船传统、中型、帆橹兼用和哨探任务；船名不能直接变成互斥科技树。

福船、沙船、广船可用作地区船体传统入口；海沧、草撇、开浪等须绑定具体文献与时代。明代材料将福建船分号，并把草撇、冬船等和福船大小、装具联系起来；同一材料中的“鸟船”还有不同指称，不能直接套现代“四大船型”的统一表格。[《武备志》船型图说转录][S1]

《龙江船厂志》同时列九江式、安庆式等哨船，以及按“料”区别的战座船、巡船。由此可见“哨”可能是用途、地方规格，也可能在其他地方成为号级名。该书还提示营造尺与兵部尺并用问题：本轮不将“料”直接当吨位，不将所有丈尺统一换成米。[《龙江船厂志》卷二][S3]

## 十一项可用素材

“文献可支持”只陈述本轮读到的材料，不等于完整船舶复原；游戏职责、优劣和操作规则均是本项目原创，尚未测试。以下没有给出史实航速、装甲值、防火值或统一定员。

| 条目与分类 | 文献可支持的形态、水域、任务 | 原创游戏职责与代价 |
|---|---|---|
| **福船 / 大福船**：地区传统中的大型战船实例 | 尖底、高舷；大船依赖风，深水有利，追入浅处受限。[S2] 现存造船技艺资料支持水密隔舱传统，不能反推每艘明代军船隔舱完全相同。[S4] | 深水阵地核心：承担指挥和集中火力。换取转向空间、吃水和无风时机动代价；需要浅水艇接应。水密舱只限制部分进水扩散，不赋予不沉效果。 |
| **沙船**：地区船体传统 | 平底、较浅吃水，可坐沙滩；江海运输是重要用途。[S5] 明代军议另讨论港湾协守和特定沿海条件。[S2] | 浅滩补给与侧翼运输：可走重舰不能走的潮道。换取较弱的外海恶劣海况表现；通过减载改变吃水，不额外发明历史最高航速。 |
| **广船**：地区船体传统，不能等同一种固定军舰 | 文献强调铁力木用材及修理供应困难，兼有海上作战讨论。[S2] 《武备志》转录另描述下窄上宽、桨橹装置。[S1] | 耐损近战主力：适合顶住一轮攻击后争夺位置。代价是昂贵维修、材料供应和维修时间；这是平衡方向，不是“广船碰福船必胜”的物理定律。 |
| **海沧（海滄）**：明代具体型式 / 大小序列 | 戚继光论述中比福船小，较小风力仍可行动；大福、海沧进不了的浅处再由苍船追击。[S2] “海苍”不另立新类。 | 中型护航：连接重舰和轻艇，保护运输线。代价是既无重舰的火力承受能力，也无最轻艇的极浅水通行能力。 |
| **苍山 / 苍船**：地方船式，史料兼述捕鱼来源与军用 | 帆橹兼用，船体较低，用于大船受浅水限制时的追击。[S2] 不把“苍山铁”的“铁”解释成铁甲舰。 | 近岸追击和截逃：可短时消耗划桨体力改变局部位置。代价是桨手也占人员编制，持续划行影响后续战斗；低舷增加接近高舷敌船的难度。 |
| **鹰船**：作战型式 / 装具特征明确 | 两端尖，旁设竹板遮蔽及射孔；文献提议先入敌队，由沙船随后接战。[S1] | 遮蔽接近与开路：用有向防护掩护后续登船艇。代价是射界、视野和载荷；防护不是全向护盾，也无证据支持防火免疫。 |
| **网梭 / 网船**：小型渔舟军用 | 梭形小舟，可搬拖上滩；文献分别提到哨探和狭港群集袭扰，场景不同。[S1] | 隐蔽探路、抢信标、窄水道骚扰。代价是难以承载重火力、必须靠近岸线撤离；一旦被截住很脆弱。不能因为“哨探”而赋予自动隐形。 |
| **八桨船**：以推进配置命名的型式 | 《武备志》转录将其列为哨探艇。[S1] 另一军议提出小艇增置铳手，因此不可宣称所有时代八桨船绝不武装。[S2] | 通信与侦察艇：争取情报刷新和命令传递。代价是有限战斗槽位；武装后降低通信、载人或耐久余量，不抢走苍山的持续追击职责。 |
| **哨船：九江式 / 安庆式等**：地方规格加任务名 | 《龙江船厂志》有不同地方尺寸规格；它不是跨时代统一船体家族。[S3] 外海文献的草撇哨船也不自动等于这些江上式样。[S1] | 河港勤务：巡逻、救援、接渡、引航。在项目中分别保存江用与海用实例；代价是离开适用水域后操控、载重和补给受限。 |
| **开浪船**：具体型式 / 地方称谓 | 文献描述尖头、桨橹推进；后出的汇编说明存在不用桨的变化。[S1][S2] 不能把所有“鸟船”都当开浪船。 | 短程截击艇：有限体力换逆风机动，争抢航道口。代价是撤离前要保留体力；没有体力时仍遵循帆航和水流条件。与八桨探船的差异来自装备与任务配置。 |
| **同安梭船**：清代扩展，时代单列 | 故宫资料明确其福建同安制造、商船背景，以及民间、海盗、官军共同采用；馆藏研究提供清代船图线索。[S6][S7] 本轮未完成船图尺寸复核。 | 商战改装分支：同一船体在载货、护航、战斗间换装。代价是货舱、火力、人员和航程预算相互挤占；不直接穿越进嘉靖舰队，也不因“较晚”而全面取代此前船式。 |

## 不宜硬凑为新船型

- **料罗**：本轮材料中的料罗是海防地名，不是已证实的独立船型。地名可成为战役、港口或船名，不据此添加“料罗级”。[《筹海图编》全览][S8]
- **桨船 / 划船**：先作为推进或用途标签；要成为独立可建造单位，还需指定朝代、地区、型式与装具。
- **草撇、冬船、鸟船、快船**：可保留为对应文献的名目或变体，不把异名、号级、大小区别重复算成四个船体家族。[S1]
- **蜈蚣船**：有舶来型式和仿制描述，且同一史料记有裁革与未试情形。适合“技术试制”素材，不宜直接宣布为大量成熟装备。[S2]
- **赶缯船**：本轮查到清代船政与博物馆研究线索，但未完成《金门志》《闽省水师各标镇协营战哨船只图说》原页核对。暂留扩展候选，不编造型号、定员、炮数或航速。

## 原创玩法组织建议

这些是设计假设，不是古籍结论：

1. 用“海况与水深改变职责”替代单纯大船等级压制。福船在深水顺风时拥有局部优势；潮道、无风、岛礁遮蔽让中小艇有明确机会。
2. 形成三套可切换编组：深水火力组（福、海沧）、浅水运输组（沙船、哨船）、接近与截击组（鹰船、苍山、开浪）。探船负责发现窗口，不能被一艘万能高速船完全取代。
3. 把划桨视为人员分配。划桨、灭火、装填、修理、登船争夺同一批人；玩家选择“现在追上”还是“接触后仍能战斗”。具体消耗是待实验的游戏参数。
4. 商船武装、军船运输、火攻装载都通过配置表达。火攻是有燃料、风向、友军和撤离代价的任务装载，不把每个火攻实例都变成凭空多一套船体。
5. 后续最小实验宜固定港道、潮位、风、初始距离与船员预算，比较同成本混合编组与全重舰编组；未运行前只叫假设，不能声称平衡已经成立。

## 来源、原文核对与限制

本轮读取了下列古籍的数字化转录与官方机构网页。古籍直接原文的短定位词为“全仗风势”（福船）、“帆橹兼用”（苍山）、“两头俱尖”（鹰船）；仅用来定位相应段落，不以宣传性修辞替代测量。

- **S1**：《古今图书集成·戎政典》第97卷“武备志一”，分别看广船、大福、草撇、海沧、开浪、苍山、八桨、鹰船、网梭等图说。**这是清代汇编所录《武备志》，并非本轮直接查阅明刻原本。** 文献有经验描述、主张与夸张语混合；“如飞”“不覆”“战无不胜”不能转成实际速度、稳定性或胜率。[直接阅读][S1]
- **S2**：《筹海图编》四库本卷13，实际读取了福船、海沧、苍山、鹰船、网船、蜈蚣船和兵船总说等段。与 S1 有大量继承、引录关系，不能算两份独立实战验证。[直接阅读][S2]
- **S3**：《龙江船厂志》卷二“图式”，实际读取单位说明、巡沙船、九江式与安庆式哨船。可约束分类和尺度解释；南京船厂记载不能无条件外推全国海船。[直接阅读][S3]
- **S4**：泉州市文广新局《福船制造技艺》，现代非遗说明。用于辨识船体传统与工艺，不把后世传承样式当所有明代福船的原样。[直接阅读][S4]
- **S5**：崇明区文化旅游局《崇明沙船制造技艺》，现代非遗说明。只采用平底、浅吃水、坐滩、运输等有边界描述；其概括航海性能与明代军议范围并不相同。本轮不采用文中的统一吨位换算和风级断言。[直接阅读][S5]
- **S6**：故宫南院《王得禄与同安船教师研习》，机构直接说明商、盗、军使用背景。[直接阅读][S6]
- **S7**：故宫《“再现·同安船”纪录片制作的历史考察与科技呈现》，检索摘要显示嘉庆二十二年《集字号大同安梭船图》馆藏线索；PDF 正文访问超时。只列下一步图像复核入口，不据此给出尺寸或复原。[研究入口][S7]
- **S8**：《筹海图编》全览，料罗出现在停泊、接济、防守地点序列；仅用于地名辨析。[直接阅读][S8]
- **S9**：《纪效新书》国家图书馆编号影印 PDF 的共享资源副本。检索文本可见治水兵篇，但 OCR 存在明显错字；本轮 PDF 能打开，所需原页截图未完成可读核验。有关戚继光的具体说法以上述 S2 的引录为直接依据，**不声称已完成《纪效新书》原版逐字校勘**。[影印入口][S9]

维基文库转录不是校勘定本，可能有错字、脱图、异体字和标点问题；例如网船人数、捕鱼小艇人数及某些名目的异文，不适合直接成为游戏数值。后续若要定型外观、装备数量、尺寸，应逐条绑定原页图、版本、图号和测量方法。本轮不下载或导入第三方图片，没有取得可用于游戏资产的授权证明。
