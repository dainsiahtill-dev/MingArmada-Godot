## 证据约定

“古籍有记载”不等于已经证实量产、普装、具体实战效果或精确外形。原书提出的方案、后世转引、现代机构说明、实物出土与游戏原创推演分别标记；同源转引不当作多份独立验证。数字化转录可能缺图、错字或含异体，本轮未完成全套版本图版校勘。

游戏中的优势、反制、数值方向和队伍编组均为原创提案。古籍的人数、尺度、射距、修辞和年代不能未经辨析变成游戏参数。特别区分蒙冲的跨时代变化、海鹘与海鳅、宋代虎蹲砲与明代虎蹲火炮、燃烧箭与推进火箭、普通铁蒺藜与蒺藜火毬。

## 持续探索顺序

1. 补齐全书目录到正文的映射，逐卷保留实际核读状态；不以几个熟悉器械冒充全书覆盖。
2. 核对影响模型定型的原页图、版本和异文；记录获取与复用权限。
3. 为核心元素写“玩家决策、成本、反制、反馈、任务连接”，相同功能可共享规则。
4. 选可证伪问题建立独立算法课题，依[研究流程](../README.md)实现与验证后才接正式游戏。
