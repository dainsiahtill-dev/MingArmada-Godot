## 已有参考与缺口

46条均关联了实际存在的图片路径，共53个去重图片文件。这个数字包含剧情情境、港口整图、UI截图、地图PNG和纹理；不代表53件独立原画，更不代表46项已经能直接建模。

`existingImages.role` 明确区分：

- `story-context`：整幅剧情图。只支持人物动作、气氛、局部材料和空间关系；不提供单体正侧背。
- `scene-context` / `process-context`：完整场景或同场过程图。不能把一张湾口图拆称多张独立建筑原画，也不能把战斗过程图计成多张地图。
- `map-reference` / `ui-screenshot`：已有底图或界面评审截图。不是实测海图、独立SVG原件或历史战场平面。
- `texture-reference` / `material-reference`：既有表面/植被贴图。不是模型、结构图或历史材料样本；旧参照素材的来源及分发许可仍需另审。

43条标记 `needs-concept`，3条材质/天气资源标记 `reference-needs-review`。虽然均有参考，建筑和自然单体普遍缺少隔离背景、无人物遮挡、接口可读的独立结构稿。

已目视核对 `port-hub-v2.png`、平户屋檐场图、无名湾口场图及1646福建门口场图。其他链接核对了文件存在及当前剧本/清单关联，未逐张进行完整形制验收。

两处不能直接复用的年代/地域问题：

- `docs/design/game-ui/prototype/assets/port-hub-v2.png` 有日本城楼背景。石堤、木货栈可作局部参考，不能整图标成厦门港。
- `assets/art/ports/xiamen-harbor-v1.prompt.md` 明写约1661、虚构福建港。其材料和气氛可以参考，但不能当1621—1646当前故事的精确港区原画。

## 优先补的三套建筑原画

1. **澳门华商货栈**：为 `building-macau-warehouse` 及货栈门面/墙/坡顶提供统一结构。1621澳门，朴素木梁柱、灰泥/石墙、大货门、低石基与踏步、旧瓦坡顶；货物单独摆放。先出独立建筑原图，再补正侧背和有限剖面，锁定门面、侧墙、屋顶接口。不要复制教堂或把后世外立面当当时形制。
2. **平户邻里小木屋**：为木墙、住宅屋顶、门窗及家居场景服务。约1623—1630的普通单层居所，窄檐、板壁、低门槛、极小起居区；不是寺庙、城堡或现代和风旅馆。现有剧情图只见局部檐下，不足以建整屋。
3. **福建郑氏居所**：为住宅灰墙、门窗、瓦顶与家宅场景服务。1630—1646，有限家居围合、石门槛、读书区与面海出入口；体面而朴素，不宫殿化。没有已证宅址平面，必须在图注写明创作概念。

这三套应分别保存可追溯的独立原图；不能只交一张混合港景、多个建筑挤在一起的气氛板。后续再补木码头/石堤拼接段、修船支架、住宅门窗接口、自然六基模轮廓稿，以及外海/港口/近岸水道的可玩平面草图。
