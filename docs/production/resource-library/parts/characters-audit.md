# 人物与NPC资源审计

日期：2026-10-22。范围：当前《一官入海》43场与现有72页UI，登记资源生产身份及复用职业。交付数据为 [characters.json](characters.json)。

## 核验依据与口径

- `docs/narrative/zheng-zhilong/zheng-zhilong-story.json` 与上层 `docs/narrative/zheng-zhilong-story.json` 已逐字节比对，一致；当前版本均为 `v4-maritime-illustrated-2026-10-22`，6幕、43场。本清单采用带目录版本以便相对图片路径能正确解析；上层仍是既有生产预算引用的镜像。
- 读过当前总人物表、43场对白发言人、涉及所有次要人物的正文段落、`docs/design/game-ui/production-assets.json`、`assets/models/sailors/sailors-manifest.json`、UI中CREW/岗位，以及 `prototype/ships.css` 图集坐标。
- 历史/原创分类遵循当前剧本角色表和场次史注；本子任务没有另做人物史源考证，不把创作面貌称为真实肖像。不从旧版剧本或通用人物画补造新人物、新航次或新死亡方式。
- CodeGraph无索引状态由主任务确认，本子项使用文件证据；不宣称进行过CodeGraph代码审查。
- `named-character` 是“稳定的独立人物身份”，包含未具名但家庭关系明确的田川幼子、阿旺女儿。`npc-archetype` 是可复用的职业/场次功能，不等于场上演员总人数，也不是需要另建28个全身基模。
- 同一人的别名、童年/成年、官袍/短衣、负伤/老年不增加人物数。仅提及的名人也纳入全游戏信息资产统筹，但 `appearance=mentioned-only`、`modelRequired=false`；P2是可选信息肖像候选，不是假定已有新场次。

## 与旧生产预算的差异

- 旧 `production-assets.json` 的“人物身体与头部=16”是3个身体基模+13个头部基模，不是16个人。旧 `art-portraits=16` 是生产目标，不代表当前已有16张独立脸。
- 旧专属头部覆盖8个独立人物：郑芝龙、田川氏、郑成功、林阿旺、林阿禾、陈添、杜七、阮老六；郑成功和阿禾分别有幼/成年头，不能因此增加人物身份数。
- 黄程、吉平、马努埃尔、阿隆索、安东、依斯迈等在旧预算走共享地域头部变体。本表保留独立身份、固定形变要求，未强行让每一人都新增一个基模。
