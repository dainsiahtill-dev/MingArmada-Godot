# R10a 帆形 A +0.06：作者源与 CPU 结构证据

状态：**单项未接受候选**。只实现 [R10 预注册](../R10-SAIL-FORM-BRIEF.md) 的 A +0.06；A −0.06 和 B 尚未构建。未修改正式游戏默认、研究演示或生产阴影。以下证据不能代替画面、运动、净距或游戏验收。

## 构建与范围

- 从原 R7c 作者 Blend 重建三档帆，原布面函数与绑扎和 12 次反解共用新宽度函数；保留 `furl`、`inflate` 两个形态键。作者源为 `assets/production/hero-fuchuan-blender/hero-fuchuan-v3-r10a-author-02.blend`。
- Blender 三次进程的原始输出、日志及哈希收据在本目录；`blender-lod0-process.json` 至 `blender-lod2-process.json` 均记录成功。中间 GLB 的持久副本位于 `assets/production/hero-fuchuan-blender/r10a-author-02-intermediates/`。它们是帆数据来源；LOD1/2 的非帆部分并非对应档位，不能直接当作完整模型使用。
- 可供后续试验的完整候选为 `assets/models/hero_fuchuan_v3_r10a/fuchuan-lod0.glb` 至 `fuchuan-lod2.glb`。受限包装从各自原 R7c GLB 出发，只引入对应帆材质面的位置、法线及两个形态键的位置、法线。稀疏形态访问器转换为独占的稠密数据并追加；根资产身份、受影响访问器边界与缓冲长度随之调整。它不是 Blender 对整船的全量重导出。
- 首次作者脚本因旧源码表达式的精确匹配失败而停止，失败过程保留在相邻 `r10a-author-01/`。独立验证器的 `r10a-independent-delta-03.json` 因局部命名遮蔽失败，修正后以 `-04.json` 为当前结果；未将这些失败描述为通过。

## 已验证

[独立差分报告](r10a-independent-delta-04.json) 分别比对三档原 R7c、Blender 作者输出和包装候选，并校验作者进程收据、源文件哈希和输出哈希。每档三个帆、四种材质面的 72 项目标属性与 Blender 输出一致；其余未声明的 JSON 与二进制数据保持精确一致。三角索引、UV、顶点色、材质、非帆几何和层级均在此精确比较范围内。比较允许帆数据本身及上述必要的包装元数据变化。

按原 nominal UV 核对布面肩部公式，三档最大误差约 **0.858 微米**，布面 Y 未改变；主帆最大位置变化约 **0.132 米**。竹桁、缝线和绑扎的反解残差仅为诊断值，不能代替几何接触、穿插或净距测量。

`python -B -m unittest tests.test_hero_r10_sail_formula tests.test_hero_r10_sail_pack tests.test_hero_r10_sail_delta`：9 项通过。覆盖公式端点、反解、受限包装及对 UV、索引、无关数据和作者收据篡改的拒绝。完整过程输入、哈希及逐项数值以本目录 JSON 为准。

尚未执行 Godot 加载与真实可达形态、完整离散状态的布与桅最小净距及桁/布接触、新穿插、三桅旋帆、三档 LOD 动画和切换；也没有真实 GPU 连续画面、完整世界和性能验证。故无法断言满足预注册的 2 mm 净距门槛，更不能接入正式默认。后续需在隔离试验中与 R7c 及其他预注册候选按同一相机、光照和动作盲审，并按原合同验证后再考虑生产接入。

## 后续静态目检与单帆态观察

R10a 的三张 Blender 原图在 `blender-review-01/`，R7c 的对应原图在相邻 `v3-r7c-authoring-review-01/`。逐对目检 hero、stern 和 hull-detail：整体三帆比例、轮廓和横桁节奏几乎一致，局部肩线变化很弱，尚未观察到可辨的整体艺术提升。细节图侧重下缘和船体，不足以评价帆顶。两组图是静态作者视图，不能代替正式游戏主镜头或连续动画。

正式镜头 FOV 55°、900 像素高时，假设帆位于 58–80 米深度且 0.132 米变化方向垂直视线，针孔模型约投影为 1.43–1.97 像素；方向、真实深度和透视位置均会改变该值。这是量级估算，不是实机像素测量。现阶段保留候选及证据，不以这项细微变化作为生产艺术改进，也不继续大规模计算；其他帆形/桁序候选仍须独立制作和比较。

单次 [LOD2 主桅试算](r10a-clearance-01-pilot.json) 在展开度 1、鼓帆 0 时，布—桅三角面最小间距基线和候选均约 91.718 mm；布—竹桁两者最小距离均为 0，各有 84 对三角面落在 0.1 微米近接容差内，候选无新增对应索引。近接可包括接触和穿过，不据此认定是否穿插。这只是单帆态，不构成预注册的完整净距、接触或动画验证。试算后分析器增加了严格横穿检测，报告绑定其试算时旧版脚本哈希。
