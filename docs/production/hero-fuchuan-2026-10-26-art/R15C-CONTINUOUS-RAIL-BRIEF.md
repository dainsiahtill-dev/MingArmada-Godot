# R15c 原栏整体重塑：制作前预注册

2026-10-27。R15 首板像贴片，R15b 新旧栏与板件仍发生实际三角面穿插。用户要求有艺术感的完整船，本候选不再叠加第二套船首板、舷带或艉栏，而只在独立 R9b Blender 作者文件中，以同一个连续位移场重塑原 `bulwark_rails`。保留相同 R9b 帆色、帆形、桅杆、船体、甲板、船员、炮与舵，以单因子判断轮廓。

## 先测得的原始连接

[真实 Blender 基线](r15c-baseline-rails-01/RAIL-COMPONENTS.json)中 `bulwark_rails` 是一个对象、4008 顶点、3000 面，但包含 **168 个拓扑分离分量**。对船首与艉部选取的 [26 对顶栏/立柱](r15c-baseline-rails-01/JOIN-BASELINE.json)，26 对都不是焊接同一拓扑分量，静态三角面最近距均为 0，且均有严格横穿；这是源船已有接合情况，不能把它描述为已焊接，也不能把横穿数非零直接认定为新问题。浮点三角面检查不等于精确谓词或动态安全。

## 可复现的单一位移场

原作者坐标以米计，x 横向、y 向上、z 正向船首。记 `S(t)=0` 当 t≤0、`S(t)=1` 当 t≥1，其余为 `t²(3−2t)`；`sheer(z)` 和 `quarter_y(z)` 使用 R7c 作者原函数。所有 `bulwark_rails` 顶点都使用同一确定性映射 `(x,y,z) → (x,y+Δ,z)`：

```
B(z)=0.85 sin²(π(z−10.3)/5.4)       当 10.3<z<15.7，否则 0
A(z)=0.55 S((z+15.6)/1.0) S((-9.8−z)/1.0)
Δ=B(z) S((y−sheer(z)−0.85)/0.49)
  + A(z) S((y−quarter_y(z)−0.30)/0.46)
```

首、艉范围互不相交；最大位移分别 0.85 与 0.55 米。顶栏、柱和下栏如果位于该空间，都由同一场处理；低于相应高度阈值的顶点及区间外顶点保持原样。x、z、所有面连接、UV、材质和对象层级不变，不删面、不加部件；原 hull、deck、waterline、隐藏阴影代理、八门炮及 socket、舵、桅帆和船员接口保持原样。连续模型的 Jacobian 行列式 `1+∂Δ/∂y≥1`，因此不会因该连续映射在 y 方向折返。但 Blender 仅对离散顶点采样、面内线性插值，**该结论不能推导离散三角网格的零缝隙或无新增接触**。

## 拒绝和后续门槛

制作前固定 R9b 作者文件、原脚本与本页 SHA，保留独立可编辑 Blender blockout、真实进程和同灯同镜头三视图。独立重新打开两文件：检查除 `bulwark_rails` 以外原对象数据及帆布图片一致；原栏拓扑、UV/材质与非目标顶点精确不变；逐顶点位移符合上述公式；拒绝零面积或翻转面。用同一 26 组栏/柱实际三角面重算最近距、横穿数与源对照；出现大于 0.01 米的新间隙、明显裂开或新增严重互穿即拒绝。该距离阈值是工程筛查值，不是人体或艺术感知标准，不能因为满足它就跳过近景目检。

同帆色配对图须在常见 300–400 像素船身视距看到首/艉完整轮廓更协调，近景的原柱、横栏、舷侧和其余甲板不能断裂或变形突兀；不明显、扭曲、穿插恶化、遮炮或破坏可读性则拒绝。只有静态美术与结构筛查都有实际收益后，才研究帆/索、炮后坐、舵、船员和阴影、三 LOD 与真实游戏连续 GPU、成本及完整操船；不得把本 blockout 当正式游戏资源。

本文件是在 R15c 作者制作前记录，尚无 R15c 模型或截图。

## 实际 blockout 与结果

随后完成独立 R15c Blender 作者副本、同机位三视图和[重开审计与接缝复测](r15c-blockout-01/RESULTS.md)。原栏拓扑、UV 与材质以及其他对象保留；26 对抽查的最小距离没有新增可测间隙，但原有的横穿计数在部分栏柱接合处增加，不能据此认定连接自然。三视图中首栏出现明显尖折、艉栏局部凸起，且变化集中于细栏杆，不足以形成协调的整船轮廓。按预先标准拒绝 R15c，不接研究入口或正式船模；该结果不证明全船碰撞、动态、LOD、GPU 或人工游玩状态。
