# R10 福船帆形与桁序：独立造型对照（预注册）

2026-10-27。当前R7c/R9三帆在游戏远景仍容易读成三块规则梯形；只换红色不解决这一大形。用户希望船体有艺术家的审美。继续沿用现有 `hero-fuchuan` 课题，先在真实Blender模型中做两种独立、可否证的造型试验，保持炮位、船体、舵、甲板和其它组件；两因子不得先混合后挑结果。

## 现有合同与基线

以R7c三档GLB与作者Blend为基线，SHA见[R9预注册](R9-CINNABAR-BRIEF.md)。原帆 `B(v)=W(1+0.10sin(πv)−0.40v²)`，上缘随u倾斜；每个`sail_N`含布、竹桁、缝、补片和绑扎，同一`furl`、`inflate`形态键驱动，`canvas`材质名是伤损识别合同。nominal UV决定原布纹和破帆锚点。坐标与尺寸以米为单位，形态值为0–1；无随机输入。

## 分离候选与取舍

1. **A：轮廓肩部**。只改变帆的宽度为 `B(v)+a·W·sin²(πv)·(1−2v)`；先比较三个独立共同系数 `a=−0.06 / 0 / +0.06`，端点宽度不变。其视觉差异可能过小或更机械，按实际盲审结果拒绝。用于帆布、竹桁、缝、补片、绑扎的表面函数和12轮形态逆解必须共用同一宽度；不得只移动外轮廓造成脱节。
2. **B：桁序节奏**。只将原均匀行参数 `t` 映射为 `v=t+εsin(2πt)`，先比较 `ε=−0.02 / 0 / +0.02`。导数下界约0.874，九桁顺序不会在连续公式中反转；仍须测导出后三LOD与形态。布网格每行、竹桁、缝线、补片及绑扎同步采用同一v，纹理和伤损UV仍为原nominal `(u,t)`；不能把v写入UV造成破帆锚点变化。

相比只改色、叠装饰或把横桁随机抖动，受限轮廓与节奏有明确对照和可回退参数。历史形制不确定，候选是对参考图的审美演绎，不宣称复原考古原船。暂以原R7c颜色比较形体，避免颜色与形体合成因子；用户可见最终材料另按R9实验决定。

## 构建与否决标准

- 新建候选作者Blend和GLB目录，不覆盖R7c/R8b/R9。三LOD的非帆节点/父链、船壳与水线、三桅、舵、炮和crew挂点严格不变；帆组拓扑与UV、`canvas`名和图片保持原合同，只允许预先声明的帆组位置/法线/形态差异。若Blender全量重导出带来无关UV漂移，则使用受限包装并单独验证，明确不称完整重导出。
- 使用真实运行时耦合域：`furl=1−deployment`、`inflate=sign·min(1,wind/18)·health·deployment`，测试deployment 0/0.25/0.5/0.75/1和实际可达的鼓帆极值、0值、三桅旋帆及三LOD。比较布与桅净距及桁/布接触；不允许原本分离的面发生新穿插，最低净距不得比同基线减少超过2mm。绑扎本就环绕桅杆，不套用布面净距规则。
- 真实Blender前/侧/艉与同正式主相机正反光GPU原帧，比较轮廓、桁序自然度、布与船体主次；任一项变差、帆显得破碎/失真、运动中脱桁或产生明显闪烁即不接受。需要连续原帧、损伤阶段、LOD转变和完整世界另行验证，不凭节点数或静态对照称最终通过。
- 不动原生或模板阴影投射策略，阴影点划作为另一已有研究问题；正式生产默认不变。既有演示需在候选可用时登记可切换项并更新本课题；独立结果和真实游戏入口/成本都达门槛后才可考虑正式接线。

此文为建模前预注册：尚未修改造型或运行候选。公式和预估有边界，实际Blender/Godot结果是决定依据。

## A +0.06 实际结果与更明显候选的预注册

随后制作了真实Blender R10a、三档有界GLB及严格独立delta，原R7c全保留。三视图同灯光目检及独立复审认为肩线变化极轻，无法辨认出足以改善整船审美的收益；最大布位移约0.132m，正式镜头约1.4–2.0px只是估计，不是实际游戏像素测量。单次LOD2主帆净距pilot在基线和候选均记录到布桁距离零，此结果不能区分接触与穿插，也未覆盖其余状态。R10a不进入生产，未开展117态大矩阵；完整证据及保留的失败在[r10a结果](r10a-author-02/RESULTS.md)。此前计划中的 A −0.06及B候选尚未运行，不能说它们已被验证或否决。

为验证轮廓是否能在正式视距形成可读改进，事前另登记 A +0.20（新版本 `r10a2`），公式、单一变化部位与无关组件的严格约束不变；模型更明显改变形态，不能外推 +0.06 的净距或结构结果。须先做参数域的有限采样与拒绝负雅可比，实际Blender前/侧/艉及正式镜头基线配对，候选仍需完整耦合帆态、三LOD、布桁/布桅接触与穿插筛查；变形看不出收益、出现折返/穿插或破坏收帆即拒绝。保留 +0.06，记录选择较大参数是根据实图作出的后续新假设，绝不把它写成事前既定结果。

实际 R10a2 作者Blend及三档有界包装已制作；离散筛查和严格声明外结构对照通过，实际Blender三视图退出0、源不变。主线与独立艺术审阅均认为变化仍需盯住边缘才能辨认，三帆仍太相似，局部帆边折点及露出的桁端反而更明显。根据预定的“看不出收益即拒绝”，此单因子候选保留研究资产但暂不进入正式游戏，也不扩大动态矩阵作为美术通过证据。此结论仅限固定Blender视图，未测游戏中的动态与性能。下一造型探索应重新设计三帆相互比例、倾角和层叠节奏，而非继续简单放大相同肩线公式。未执行的 −0.06和B仍保持未测。
