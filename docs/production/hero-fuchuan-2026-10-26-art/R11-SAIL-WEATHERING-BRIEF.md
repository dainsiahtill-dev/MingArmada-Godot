# R11 帆布分幅与褪色：独立艺术对照（预注册）

2026-10-27。R9b在真实主镜头下让朱砂帆从青海中更易辨认，但独立目检认为三片帆仍偏平、色阶过于一致，参考画的分幅与旧化节奏尚未建立。本项在既有 `hero-fuchuan` 课题中，以R9b为单一对照，试验少量分幅色差；不能把换色视为帆形或整船艺术完成。

## 候选与不变量

沿用已有canvas的 `SailAge` 顶点色和现有伤损shader，不新增shader、贴图、阴影、环境或全场光照算法；R9b生图纹理、UV比例、船帆几何和材质不改。为三个帆组分别指定低饱和的手工色阶，按照nominal帆高t在9个桁位之间平滑插值，均匀性和动态效果在GPU实际判断。此处是有限的美术参数，不由随机数或时间驱动：

```
sail_0: [0.94, 1.02, 0.92, 0.99, 0.95, 1.03, 0.93, 1.00, 0.95]
sail_1: [0.96, 1.04, 0.94, 1.00, 0.91, 1.02, 0.95, 0.99, 0.94]
sail_2: [0.92, 1.00, 0.96, 1.03, 0.94, 0.99, 0.91, 1.02, 0.95]
```

系数作用于原有canvas顶点RGB，区间0.91–1.04；同一顶点的多loop UV必须一致，否则拒绝。仅canvas表面有变化；bamboo、hemp、canvas_seam以及其它材质和物件的顶点色不改。实际值按原材质合同限制在合法范围，不重排UV或改变损伤位置。颜色存储在线性空间；新分幅会与原有SailAge自然旧化叠加，不将表中系数直接当最终屏幕RGB，也不杜撰历史纹样。

可编辑Blender作者文件、三档GLB、以及R9b基线各另存并登记SHA。允许差异限定为三组帆canvas的 `COLOR_0` 及必要buffer存储；节点、索引、POSITION/NORMAL、furl/inflate、所有UV、材料/纹理和其它surface的数据必须精确一致。若Blender重导出存在无关UV漂移，按原GLB构造受限顶点色包装并独立复核，明确不是完整Blender导出。原数据、失败和历史回执不覆盖。

## 接受与拒绝

同正式相机、环境、光照、AA、帆角、三船/船员状态比较R9b与候选；另外实际Blender视图、正反光、细节/伤损及可达的收帆、转舵和LOD分别验证。轻微分幅应在主镜头产生可察觉的结构层次，同时不变成横向条纹、棋盘、过度发花或可见重复；不能压黑帆、掩盖真实竹桁、误染索具或使破帆位置漂移。若实际对照看不出改善，或色阶过强、损伤/透光失真、动画中闪烁，则拒绝候选。

三LOD的布与桁形态绑定、帆伤100/80/60/30、部署0/25/50/75/100、炮舵及其他材质不变须通过实际合同；对照仅证明预先规定状态，独立实验不能代表全场性能或原生完整驾驶。用户的UI克制要求同样作为艺术判断参考，不借故堆叠额外装饰。只有独立验证与实际游戏入口验证通过，才考虑生产接线。

此文为造型/材质改动前的预注册，尚未制作候选或运行GPU。

## R11首轮结果与R11b新假设

随后已完成真实R11 Blender作者文件、三档严格有界COLOR_0改写和独立校验；原R9b未改。Godot实际导入、三LOD/三帆canvas和伤损Shader绑定通过328项；研究台接入另有74/0。首版构建曾因五个浮点分量1 ULP不一致被拒，固定同一求值顺序后精确通过，未放宽要求。

已在隔离进程的同一正式主场景条件分别拍摄R9b和R11，两组均2帧/0失败；实际相机、目标、风、光、画质、AA与共用源码散列一致。两组R7c基线原图像素的平均绝对差约0.000017/255、仅3像素任一通道差超过3，故当前对照背景差异很小；R11与R9b在船帆区域确有像素变化，但主视距下独立美术复核认为色阶改善太弱，仍呈平整色板，未达上面的接受条件。因此不继续把R11作为正式成品；上述结论只针对单一日光静态视角，不能外推其它光照或动画。

为减少单向条纹并让不同帆有自然、可见的旧化，新增独立R11b候选：仍以R9b为基线，仅改canvas `COLOR_0`；帆高t取0/0.25/0.5/0.75/1，横向u取0/0.5/1，分别给每帆手工系数矩阵，先在两维用smoothstep插值。此方案是根据R11失败图提出的新假设，不是对首轮已定系数的事后改判：

```
sail_0: [[1.04,0.96,0.88],[1.10,1.03,0.93],[1.04,1.11,1.00],[0.95,1.04,0.91],[0.90,0.96,1.01]]
sail_1: [[0.99,1.10,1.02],[0.94,1.12,1.04],[1.02,1.07,0.90],[1.10,0.98,0.88],[1.01,0.93,0.96]]
sail_2: [[0.92,1.01,1.08],[1.01,1.09,0.95],[1.11,1.00,0.90],[1.02,0.91,0.98],[0.94,0.99,1.04]]
```

所有系数作用于原线性RGB后仍按原合同钳制；GLB UV的v与Blender方向相反，必须使用真实导入及逐点映射证明。只允许目标canvas颜色变化，三LOD的非帆、非canvas面、PNG、UV、几何、形态、材质及节点严格不变。若色阶仍不可见，或出现明显斑驳、横纹、过暗、收帆/破帆异样，则拒绝；不以增加对比为目标放宽艺术标准。需新作者Blend、独立GLB、失败夹具、同镜头原帧和动作证据，完成前不得接正式默认。

## R11b 正式场景对照结果

独立 R11b 作者文件、三 LOD 和实验台接线完成后，以隔离进程分别采集 [R9b](../../research/evidence/hero-fuchuan/r9-cinnabar-20261027/world-r9b-r11b-pair/LIGHT_STUDY.json) 和 [R11b](../../research/evidence/hero-fuchuan/r9-cinnabar-20261027/world-r11b-pair/LIGHT_STUDY.json) 的同一正式场景，两组均为 2 帧、0 失败、进程退出 0。独立核对相机、风、实际光与环境、画质、抗锯齿及 13 个共同源码哈希一致；状态中仅含进程号的 battleId 不同。两组 R7c 基线全图 RGB 平均绝对差为 0.000022/255，帆区为 0。R9b 与 R11b 在帆区的平均绝对差为 0.985/255，确有颜色变化，但主线和独立美术复核均认为正常游戏视距几乎不可辨，仍是三块相似的平整红帆，未达到预先规定的艺术收益，故暂不接入正式默认。

该结果只证明单一日光冻结视角下的对照；R11b 未进行动态、碰撞、性能或操作系统实际游玩验收。原始模型、截图和失败结论均保留。后续帆型方案另见 [R12 预注册](R12-SAIL-SILHOUETTE-BRIEF.md)。
