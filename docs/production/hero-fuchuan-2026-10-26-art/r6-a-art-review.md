# r6-a 船尾几何独立美术复审

2026-10-26。直接查看 `v3-r6-a/` 四张 Blender 实图，并与 r4 的 `stern-quarter.png`、`deck-detail.png` 同角度对照。未改代码、模型或生成器，未启动 GPU/游戏。本报告判断的是当前静态几何观感，不认证动作、导入后的阴影或性能。

**裁定：可继续下一次只合并舵铁件的构建。尾墙已实质改善；舵叶有明确但较克制的改善。当前四视角未见必须先返工的视觉阻塞。** 下一构建若确实只合并 Mesh 而不改变顶点位置和材质表现，预计不改变本轮造型判断；本报告不提前认证尚未生成的结果或 draw 成本。

## 同角度结论

| 审查项 | 判断 | 实际图像依据 |
| --- | --- | --- |
| 大块平直尾墙 | **实质改善，幅度明显** | r4 后横墙是整片同光面的宽木板；r6-a 已有中央面、转角、角柱、两处尾窗及连续压边。`stern-quarter` 中尾面与侧墙有不同受光，外轮廓也发生转接，不能只解释成“在原板上贴两扇窗”。 |
| 板状舵 | **改善中等，仍保留宽平木叶感** | 上肩不再是完整直角切口，下脚圆收，外缘有更清楚的厚度与铁带连接。侧视仍有较长直边与宽平表面，距离参考图的自然肩脚过渡还有余地；木舵本来就应保留板材构造，不需要为了消除平面而做鼓胀水翼。 |
| 过度窗格化 | **当前未过度，宜停止继续加窗** | 新增窗集中在紧凑尾楼，主要船舷仍是连续实木与炮口，窗没有扩散到全船。`deck-detail` 的窗洞能读出深色内底和框的前后层次，优于 r4 贴在墙上的格栅。尾窗/侧窗较规整，略有小屋感，但仍在可接受的结构层级内。 |
| 甲板薄盖感 | **明显减轻，未完全消失** | 压边、角柱和膝材使上层甲板有承托，窗顶与檐板之间的层次可读。浅色甲板大平面仍很亮，部分角度保留细黑阴影线；当前更像檐板下的正常阴影，不再是 r4 那条解释不足的整段悬缝。 |
| 舵杆口与连接 | **当前姿态未见明显穿插** | 尾护栏中线留口使长舵柄的去向有解释，中央不再被完整横栏封住。舵上肩与尾壳也有相接关系；当前四张静态图未见铁带悬空、舵杆穿栏或明显漂浮支承。不能由此扩展为全舵角扫掠已验证。 |

## 阻塞项

**本轮静态艺术检查没有发现阻塞项。** 窗洞深度、中央舵杆口和新增支承都在可见图中成立，不需要先通过增加更多窗格或装饰继续打散体量。

## 非阻塞项

1. **舵叶仍稍像精修过的厚木板。** 肩部转折和圆脚已有效；以后若仍需精修，优先调整肩部到工作段的连续曲线、后缘收薄的光面，不再增加铁带数量。当前不建议大改面积、跨度或转轴。
2. **尾楼窗框节奏偏整齐。** 保留现有数量即可；如果继续打磨，应微调窗框与柱的主次和局部深度，不复制更多同尺寸格子。否则尾楼容易逐渐变成房屋立面。
3. **上甲板边缘还偏直、偏亮。** 相比 r4 已更有厚度；未来可在有限端部过渡中减少“整条尺子”的感觉，不必用翘檐或更多托架填满。
4. **侧后视的尾柱、窗、膝材略集中。** 当前没有压倒帆和船腹，但后续应收住新增细节。主角船的质感应继续来自轮廓、截面和连接，而不是增加更多小件。

三桅、四炮/侧与主船比例在四张图中保持原方向；炮口精确位置、32m数据和可动合同本轮未通过源码或运行重新认证。只合并舵铁件是合理的下一步工程整理，本轮没有提出位置改变或扩展海面/岛屿的要求。
