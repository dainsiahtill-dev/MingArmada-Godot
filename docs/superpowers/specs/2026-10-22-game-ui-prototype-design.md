# 完整系统与UI原型设计

用户明确要求从剧情列出全部系统并生成所有页面，且确认交付完整可点击网页原型及全部页面预览。采用30系统、72独立页面覆盖；优先级仅表示未来游戏实施顺序。

页面按主菜单/剧情、航行海图、舰船战斗、港贸船员、日志关系家庭分组。页面形态依据任务变化，避免72个相同卡片。复用已有港景、人物、货物、弹药与剧情图；新增完整福船检视插图。继承深青铜金旧纸视觉。

静态经典脚本、共享组件与内存演示状态；资源、货物、修船、招募、装填、寄信等可点击观察反馈。提供系统表、剧情映射、顺序流程、全页预览、搜索和深链接。原型不声称Godot玩法或经济已经接入。

验收：所有72页有专用渲染与有效入口；剧情映射有效、图片有效、导航无悬空；浏览器实测关键流程、键盘与窄屏；逐页截图生成可审阅预览。保留当前游戏和剧情网页。
