# 主角福船复古材质升级

用户明确要求使用生图模型生成更好看、更复古的贴图，并验证真实效果。沿用已授权的船模制作和接入任务，直接制作可检查候选。

方向：低饱和暖木色、海风晒旧甲板、象牙色麻帆、暗锻铁与少量锈迹。保留现有红赭护舷和船体轮廓。材质有使用痕迹但保持可驾驶旗舰的完好结构，避免把整船做成废船。

方案：继续程序色纹成本低但缺乏手工材质变化；整船烘焙成一张带阴影图容易锁死光照且破坏独立组件；采用四张生图 albedo + 既有几何和运行时照明，按材质调粗糙度。基础色图不冒充法线、粗糙度或科学扫描。

执行：内置 image_gen 每种材质独立生成，保留原始输出和提示词。候选保存于新目录；原 v1 GLB、blend、脚本、GPU 和原生证据保留。木纹沿长轴设置 UV，帆布归一化 UV 保留损伤合同。

接受标准：原始生成图无文字、透视、边框或强光照；颜色和纹理重复在真实船体可接受；固定镜头日光、反光面、收帆、战损图检视；连续 GPU 与原生游戏实际操船；导出模型仍保持三 LOD、动作和炮口合同。近景检视不能替代通常航行视距。

课题沿用 hero-fuchuan，不重复新建。先独立候选预览，再更新默认资源引用；生成图不算接入或 GPU 验收证据。最终报告区分旧版本回归、贴图版新验证与未测的性能/导出包。
