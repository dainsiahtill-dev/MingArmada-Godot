# 已完成参考效果的 Godot 整合

用户要求直接吸收现有 REA 交付，不再向 REA 分派研究。沿用现有海面、航海与事件时间；先效果，不做性能专项。此次只移植已经完成的粒子和云雾模块。

1. 资源专家导入四份粒子 NIF 结构、云雾原型、原 DDS 全 mip 及既有校验样本。源目录只读。
2. 算法专家移植发射窗口、CRT 随机、粒子池、修改器顺序、原网格与动画；提供原生变步长接口及明确标注的产品观察时钟。
3. 云雾专家移植原云原型与创建、旋转、billboard、雾原型控制器；世界位置属于目标游戏适配。
4. 主 Agent 接入真实炮火、水面碰撞事件。保留已有效的水面波浪和波面贴合反馈，替换旧近似源粒子层；保持只读物理接口。
5. 执行来源样本、事件去重、暂停、回退、迟到事件与清理测试；实际 Godot GPU 截图、逐张亲自检查。局部通过不等于整个游戏目标完成。

本轮不改海战物理、经营状态、存档格式；不提交、推送或导出。原作完整 DX9 画面与未知实时相机不作为已恢复内容。
