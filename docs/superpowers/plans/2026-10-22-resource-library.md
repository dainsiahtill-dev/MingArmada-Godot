# 全游戏资源统筹与原画库 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox tracking.

**Goal:** 从当前43场剧本、72页UI及已核83个基模预算建立逐项资源总表，并在资源目录准备可追溯的草图、原图与建模说明。

**Architecture:** 三个独立分片核人物、环境及装备道具，root统一船型、稳定ID、去重、图像归档与资源图鉴。生产参考库放在 assets/production/，通过 .gdignore 避免原画被Godot自动导入；运行时资源仍走原有引擎资产合同。现有83模型预算保留，明示详细资源条目与基模数量的区别。

**Tech Stack:** JSON资源清单、Node构建与校验、原生ImageGen、HTML/CSS资源图鉴。

- [x] 核对最新剧情、UI清单及实际资源，分别列独立角色、NPC职业、火炮、个人火器、冷兵器、弹药、建筑、沿海设施、地图、自然、船舶及道具。
- [x] 为所有资源赋稳定ID，标明用途、优先级、变体、复用与来源，处理年龄、职业、船名、地标和模块的重复计数。
- [x] 在对应分类/资源ID目录归档现有原图；保留原件与来源，不移动现有生产文件。
- [x] 对关键缺口生成独立概念原画，记录原始提示词与生成出处，逐张检查后采用。
- [x] 为道具/建筑需要的技术草图提供有具体结构信息的可编辑图，不冒充实测工程图；每项可追查实际图像或其参考画面。
- [x] 生成总表、分类数量、机器可读清单与可筛选资源图鉴，链接原UI的模型与美术入口。
- [x] 执行ID/数量/路径/图片解码/来源/覆盖校验，浏览器核对图鉴、分类、检索和链接。
- [x] 保存交付报告，逐项说明现有参考、生成概念、生产模型与待研究形制的边界。
