# 参考地形与正式海岛细节融合

用户指出现有岛屿圆丘形态平淡、细节不足，明确同意海岛用参考数据。采用已导出的 Cat Island、Coastal2、Virgin Islands 原始高度数据作为正式岛形基础，结合明郑港口、岩岸、礁石、树林、岸边营地及码头生活细节。

现有原高度数学保留为兼容默认值与旧模型对照；正式游戏场景明确启用 reference_islands 选项。统一 height sampler 供3D地形、碰撞、水深、船舶AI、浮力岸线衰减、小地图及泡沫使用，不以视觉覆盖层伪造陆地。

## 分工与接线

- 海岛 profile 专家：新纯地形 helper、HeightField 可选配置、三个数据及来源散列、profile 数学与码头水深测试。
- 根 Agent：正式 Mingqi、Career、Sail/Duel/Fleet、QA 的同一配置入口，WorldView 港口与 IslandDetails 细节，真实主菜单 GPU 验收和最终包。
- 水花专家：独立真实水柱、水环、粒子与原贴图层，保持当前事件API；不修改海岛 profile。

## 验收

- [ ] 原数据及来源哈希正确，配置复制与无效输入原子性通过。
- [ ] 港口世界身份与位置保留；码头外可安全起航，栈桥向陆端接地，浅滩航路仍有意义。
- [ ] 实际岛形具有明显不规则海岸、山脊、湾与海底渐变，三类 profile 不重复圆丘。
- [ ] 岩石、植被、生活细节在坡度/海拔合理处落地；码头不会浮在空中，装饰不阻塞航道。
- [ ] 正式相同采样服务地形/物理/AI/地图/岸线，原兼容 oracle 不变。
