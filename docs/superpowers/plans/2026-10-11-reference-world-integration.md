# 参考海岛与海面整合到正式游戏

最新用户指令：“全部整合起来”。已完成的独立预览作为源码与视觉基准，本阶段将效果接入实际厦门航海、海战与历史航程。

视觉纠偏：用户指出直接套用 demo 海浪过于死板；要求吸收新效果的优点，同时保留原海面的好部分。正式海面采用融合方案：原五波浮力、自然水纹、风向流动、碎波和尾迹，与新镜像反射、深度折射、浅水配色、真实岸线泡沫及焦散结合。消除初版规则棋盘高光和重复条纹，原始精确 demo 保留作学习对照，不作为正式世界视觉的唯一标准。

## 统一路径

`game scenes → NavalWorldView → WorldView → ProjectedOcean + TerrainChunk + IslandDetails`。原港口、海岛地理、植被、船模、水手、尾迹及已实现的炮战效果继续处于同一场景与接受时间。独立 Cat Island 预览保留用于精确来源对照。

- 正式海面：ProjectedOcean 保持已有投影网格与外部 API；style1 融合原水面细节、风场与碎波，接入 demo 的水色、吸收、深度折射、Fresnel、泡沫和真正镜像反射，style0 保留旧路径。
- 正式海岛：TerrainChunk 保持真实世界地理、碰撞、网格、植被挂接与港口支撑；style1 用源 terrainFS 沙、湿沙、草、岩石和浅滩焦散公式。
- 物理：正式游戏沿用共享的原五波 descriptor 和 8m smoothstep 浅海衰减；GPU 高度/法线、CPU 浮力、船尾水迹、炮弹与落水船员共用同一时间和水面合同。四组 Gerstner 精确预览不替换航程物理。
- 环境：正式世界绑定源天空与线性输出环境，避免再次使用 ACES 把已适配的海色压暗；标准船舶、建筑与植被保留可读日光与阴影。
- 生命周期：真实镜像视口与水层排除、返回菜单释放、质量重建、暂停/逆时与相机变化必须保持正确。无渲染层反向引用物理层。

## 分工

海面专家拥有 ProjectedOcean 与 integration shader/helper；海岛专家拥有 TerrainChunk 与 terrain shader；物理专家检查共享描述、衰减、采样/浮力并只修必要问题。主线程拥有 WorldView/NavalWorldView/场景环境接线、真实原生验收、最终发布。各方只改独占文件，保存测试与来源报告。
