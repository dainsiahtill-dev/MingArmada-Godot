Summary retains mean/max/p99, thresholds25/50/100/500/1000, longest10, event counts, and metric-window flags. Original metrics preserve FPS/p95 and rolling7200 intervals.

Godot is not a browser RAF renderer. Native `simulationMs` measures coordinator/Encounter CPU. `viewWorldMs` measures combined shared-sea presentation, actual crew/effects/world and audio CPU. Shared `NavalWorldView.apply_snapshot` currently combines view and world update: separate `viewMs`/`worldUpdateMs` remain `null`. No engine render-submit or GPU completion measurement was fabricated: both are `null`. Native world updates chunks synchronously, so pending create/dispose counts are0 with an explicit scheduling description, actual chunk/build counts and actual player-focus center. JSON labels these differences and warns that timing correlation alone cannot prove cause.

`export_diagnostics(path="")` writes/flushes/closes and parses back `user://ming-armada-performance-{ticks}.json` by default, returns its absolute path, and includes detached canonical snapshot, viewport/engine/render method/video adapter, actual intervals, summary, crew diagnostics and original metrics.
