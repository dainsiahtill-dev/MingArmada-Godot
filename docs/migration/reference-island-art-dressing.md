# 不规则参考海岛的细节布置

2026-10-11：在当前三种真实参考高度轮廓上，细节布置已改为读取实际干地、坡肩和港口支撑面。原先针对圆岛的中心林带、规则港区行列和两条空直路，无法适配细长 Cat Island、海湾 coastal2 和 virgin islands。本轮仅修改 `IslandDetails` 与原生小型模型库，不修改海岛高度、物理、AI 航路、海面或 WorldView。

## 直接发现的旧问题

新 profile 的实际初次测试为 307 assertions / 10 failures。厦门没有成功生成任何港区建筑、树木或地面路径；补给岛没有建筑或路径，仅有 3 棵树；金门只有 2 栋建筑。旧港区候选横向约 28/38 米、纵向约 65 米以上，错过了沿岸 43–55 米附近的可支撑窄平台。低坡探查还发现，厦门和补给岛高地多数非常陡，不应通过增加大树数量掩盖这种真实轮廓。

现有 `_contour` 从外海扫描首次水陆肩再二分的支持保持原样，可处理水下中心、凹湾和分离岛肩；没有恢复旧圆丘假设。

## 布置改进

- 港区先寻找可落地的渔业生活空间，再探查低地摊棚、棚屋及房屋。粗探后还会细探窄平台中的紧凑摊位空隙；每个候选仍验证实际底部网格脚点、允许地形高差和已占空间，不修改地面以强塞建筑。
- 林地从干地调查与邻域细探中选取不同坡肩，避免以几何岛心为默认树林中心。每棵 `coastal_tree` 要求高度超过 6 米、坡度 grade ≤ 0.75；较矮风弯 `shore_tree` 在高度 ≥ 1.5 米、grade ≤ 0.45 的干岸出现。这里 grade 是 2 米差分的高度梯度长度，并非角度单位。陡壁使用沿实际坡面方向的破碎岩簇。
- 原先成对的长直线碎石道改为到达已成功建筑的短曲线联络，以及实际上陆工作场的不规则石片院地。每片石都保持原坡面贴合验证；没有巨型地面板或假路面贴图。
- 新增三个原生模型：低风弯树、带龙骨/内板/船座的岸上木舟，以及带支撑杆、绳网和吊挂鱼形的晒网架。它们是环境细节，未冒充受物理控制的新舰船。渔业模型逐一检查完整干地范围和底部支撑。
- `pebble` 与 `outcrop` 原本使用完全相同的网格生成和材质色值，现复用同一只缓存网格，保留不同布置身份、尺寸及随机颜色。三种新轮廓的模型数量仍在原 24 个复用网格合同内；本轮没有开展性能优化。

港口中心装卸走道、出入港航道和既有跨港通航走廊仍保留。装饰是只读地理消费者，不移动船、修改海底或接管模拟时钟；种子和港口排序保持确定性。

## 实际已建房屋合同

新增可选 `configure(..., options.existing_buildings)`：

```gdscript
{"existing_buildings": [
    {"position": Vector2(world_x, world_z), "radius": 6.0},
]}
```

位置也可用 `point` 名称，或纯数据 `{x, z}`。提供该数组时，只避让调用者实际绘制成功的旧房屋；空数组表示没有外部旧房屋。未提供时保留原来的 9 房规则圈兼容旧调用。非法数据会拒绝配置。

正式 WorldView 应在旧房地基校验成功并实际创建后收集这些位置、半径，再传给该模块；这段接线由主 Agent 独占。这样不会把已被地基检查删除的房屋继续作为“幽灵地块”排除。下面的隔离测试没有另行绘制旧房屋，所以明确传空数组，并不声称正式世界的旧房列表必定为空。
