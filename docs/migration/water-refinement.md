# 2026-10-11 近岸海面美术细化

用户给出的 Sandcastle 参考图强调青绿浅海、可辨认的水下层次、沙底焦散，以及沿真实岸线推进的细碎白色浪花。本次在既有 Godot 海面表现层内实现这些方向，保持现有船只浮力、海面顶点位移、深水原波形和 accepted simulation time。

## 文件与边界

- `modules/scene_engine/ocean/original_water.gdshader`：只调整 `visual_style == 1` 的片元表现；原 `vertex()`、波形 include、法线贴图、相机投影和 `visual_style == 0` 保留。
- `modules/scene_engine/ocean/coastal_visuals.gdshaderinc`：纯片元沙底颜色、细胞焦散和破碎岸浪函数。通过传入的世界 X/Z、岸距、地形深度与 `simulation_time` 工作；无 `TIME`、物理模块引用或新时钟。

## 行为

浅海颜色由注入的 signed height field 混合，不以距相机远近伪造水深。在 0.4–10 米水深范围内渐隐沙底细纹和焦散网络；底纹固定在世界坐标，受细小折射扰动，焦散缓慢变化。浅海不透明度降低，让已有海底几何参与最终画面；深海继续保持蓝色并完全遮住背景。

泡沫同时受到真实岸距和浅水深度限制。岸边 froth 在约 1–3 米内渐隐，移动的波线间隔约 6 米，以约 1.4 米/秒向岸推进，在 19–25 米岸距范围内消失。第三轮将单一亮线分为窄白浪头和位于其海侧的低亮泡沫尾迹：尾迹在浪头经过后产生，沿同一相位推进，最长约 2.65 米、存续约 1.9 秒，再渐隐。约 13 米尺度的世界坐标噪声形成不规则沿岸缺口；局部碎粒打散浪头与拖尾，岸边残留 froth 随同一波周期起落。只有水下沙洲的地方可以出现浅水色与焦散，但不会凭空生成环状岸浪。保持既有原生 shore spray。

岸浪使用未折返相位的导数计算米制滤波宽度，避免周期接缝造成错误的大面积泡沫。约 0.44 米粒度的泡沫粒在像素覆盖过大时退为平均覆盖度，不保持远景闪烁碎点。低频缺口保留，浪头亮度随滤波宽度衰减，避免远景重现连续霓虹描边。此层新增五个标量 hash，无邻域循环、历史缓冲、新纹理或额外物理采样。

细胞焦散有一个 3×3 邻域循环，仅在可见浅水片元执行；使用导数扩大远景细线的滤波宽度，并相应减少线条能量，防止远景变成高亮网格。焦散的 RGB 增益约 0.035–0.05，让它处于白色岸浪之下。该复杂度的实际 GPU 耗时仍需在目标设备实测，不能从 headless 测试推断帧率。

## 本次验证

以下均通过 Godot `4.7.2.stable.official.ed1daf0bf` 原生 headless 执行，退出码 0、无 `SCRIPT ERROR`：

| 测试 | Assertions | Failures | 证明范围 |
| --- | ---: | ---: | --- |
| `test_water_probe.gd` | 77 | 0 | 48 个原 JS 波形样本；投影海面、注入时间与暂停冻结 |
| `test_coastal_waves.gd` | 1090 | 0 | 各水深幅值边界、深海原波形、梯度与法线 |
| `test_shore_field.gd` | 10 | 0 | signed RF 高度、无真实海岸的沙洲不造浪圈 |
| `test_wave_uniforms.gd` | 8 | 0 | 原五波注入、拒绝非法参数时保留有效 GPU 输入 |

这些验证保护表现层与物理的接口和原波形，不单独证明像素效果。前两轮降低过亮焦散并缩短波线间隔；第三轮针对实际截图中连续描边、缺少宽度与退散的问题加入破碎浪头、海侧尾迹和方向一致的年龄衰减。

Root 已在 Godot 4.7.2、D3D12 Forward+、Intel Arc 130T 上完成 72 帧原生 viewport 捕获，连续推进六秒模拟时间。`evidence/mingqi/native-capture.log` 有 `NATIVE_MINGQI_CAPTURE_COMPLETE ships=5 tick=660`，退出 0、无 shader/script error。Root 与独立审查亲看实际岸线 00/24/48/71 帧，并与用户最后一张 Sandcastle 图比较：浪头有推进、缺口和较淡的海侧尾迹，青蓝水色与正常船体水线保持。当前白沫仍比参考偏细、偏淡，粒状覆盖与更宽的铺开退散需要进一步美术完善，不能宣布完全复现参考。

连续捕获还发现深海透出流式海床窗口的大三角色块。CPU 投影与实际边界吻合后，只把 style 1 深海基础不透明度提高到 1；最浅水的基础值保持 0.78。同相机、同时间的第二次 72 帧原生捕获中，71 帧该色块消失。原五波、style 0、物理和时间均未改。

`tools/migration/build_wave_preview.py` 将这些真实 PNG 编码为无损原尺寸 WebP、960×540 quality 90 WebP 预览和 GIF，保留逐帧哈希、tick、模拟时间与相机记录在 `shore-waves-manifest.json`。小 WebP/GIF 为尺寸与编码转换的预览，PNG 为原始证据；循环接缝不代表原生模拟倒退。截图写盘耗时不作为 GPU 帧率或性能结论。

## 尚未覆盖

参考画面中的水下海草、珊瑚、低多边形礁石和更精细的沙滩几何属于场景资产，未在本次海面 shader 修改中实现。现有海岛结构和材质未改；不会将程序化底色描述为真实新建的海底模型。
