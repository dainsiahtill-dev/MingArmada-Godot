# 跟船与自由环绕运镜验收（2026-10-13）

已接入正式共享 `NavalWorldView`，覆盖「自由试航」与「海上明旗新生涯」。默认采用船尾侧后方的跟船镜头；右键拖动后保留玩家选择的世界观察方向，位置仍随船移动。按 F 主动恢复默认跟船角度与距离。

## 玩家操作

| 操作 | 行为 |
| --- | --- |
| 左键点击合法海面 | 原有鼠标持续航行与目标航向 |
| 中键 | 原有停船 |
| 按住右键拖动 | 水平环绕、调整俯仰；不发操船指令 |
| 松开右键 | 保留选择的观察角度，不自动强制回正 |
| 滚轮 | 平滑拉近、拉远 |
| F | 恢复船尾侧后方跟随，退出高位视角，恢复默认距离 |

暂停、港内允许观察。菜单、航图、操作面板、设置、可编辑焦点、隐藏 HUD 阻挡相机输入；GUI 消费鼠标松键或窗口失焦也能正确取消拖拽。右键与左键混按不会残留航行点击，正常左键航行仍有正例验证。两份原有 HUD 已加入中文提示。

## 实现与时间归属

- `game/presentation/world/ship_camera_controller.gd` 为纯相机控制器，接收只读船舶快照，输出眼点、焦点、上方向。没有推进 Encounter、修改船体姿态或覆盖 native 运动。
- 默认半径 68 米，俯仰 32°；高位模式半径 170 米，俯仰 58°。滚轮目标按 `exp(-steps * 0.12)` 改变，距离限制 36–220 米；俯仰限制 20–72°。
- 焦点加入约 0.65 秒速度前视，偏移限制在一条船长以内且最多 10 米。自动转镜使用最短角度路径与平滑追随；手动环绕保留世界朝向。
- 自动位置、朝向、起伏与晃动只使用已接受的 native 时间。显式输入的 yaw、pitch、radius 分别拥有平滑时间；暂停滚轮缩放不会推进尚未收敛的自动转镜。
- 关闭跟随会冻结自动移动与晃动；高位视角仍跟船。「减少动态效果」保留稳定地平线并移除船体摇晃和前视运动。
- 共享 Sea 每次既有呈现更新一次 Camera，再交给海面投影和反射。鼠标事件只更新相机意图，不额外执行完整世界呈现。地形安全检查仅一次高度采样，眼点保持在地形上方至少 4 米。
- 原独立海岛预览的自定义相机仍有最高优先级。battleId、playerId、船型变化会清理旧相机归属和拖拽。
- 生涯失焦现在明确设置 blur 暂停；「继续」清除 blur/player 暂停，其余 menu/loading/result 等暂停归属保留。恢复保留合法鼠标航向。

## 性能边界

最终源码冻结后的正式菜单自由试航短测：2 秒预热后观察 8.001949 秒，**14.496 FPS**、帧时间中位数 **68.527 毫秒**；native 推进 **8.0 秒**，所有测量帧保持前台、可见、未暂停。原始记录：[live-observation.json](../../Temp/ship-camera-live-sail-20261013-v2/live-observation.json)。

这个结果与此前约 14 FPS 的修复后水平相近，仍不流畅；单次短测不支持性能等价、长期稳定或 30/60 FPS 验收结论。本轮完成运镜及其输入/暂停合同，剩余 CPU 呈现开销继续按 [自由试航性能根因报告](free-sailing-performance-2026-10-13.md) 排查，不能用调整镜头掩盖性能瓶颈。低角度远海、浅滩边界、近景构图也仍可继续细化，未宣称整款游戏已经完成。
