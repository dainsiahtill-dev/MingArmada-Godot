## 实际验证结果

严格命令：`rtk proxy node tools/verify-game-ui-prototype.mjs --require-previews`

- 页面72/72、注册渲染器72/72、截图72/72。
- 24项静态与VM检查通过，0失败、0待补。
- 真实浏览器逐页检查：72页ID匹配，页面图像全部载入，无undefined/NaN/页面异常文本，无横向溢出。
- 390×844窄屏：72页文档宽度检查无横向溢出；另保存舰船页完整窄屏截图。此项不等于所有触屏设备的可用性认证。
- 72张JPEG完整解码，文件哈希与像素哈希均72个，无重复、无完全空白。截图使用1440×1000浏览器视口；全页导出实际宽1424或1440、高1000—1466，按原尺寸记录。
- 逐张目视审阅6张接触表，并放大审阅舰船、海图、海战、首页与总览。发现总览缩略图受HTML高度影响变形后，已修复并重新截图总览。
- 浏览器总览实际含72张图片、0个实时iframe；系统总表30行+11项底层能力，流程菜单13项；控制台本轮无error/warn。

## 真实浏览器交互验收

| 操作 | 观察结果 |
|---|---|
| 生丝买入3担 | 42两/担，总额126；银两2460→2334，库存12→15 |
| 银两不足的买入 | 拒绝成交，余额不变 |
| 船体维修 | 扣380两，船体72→100；满状态阻止重复维修 |
| 保存→买入→读取 | 购买1担后银两2418；读档恢复2460、库存12、原流水 |
| 写给平户家中并附银70 | 正文、收信人和70两保留；另记20两捎信费，银两2460→2370 |
| 展开寄件 | 能读回自定义正文、收信人、金额，状态为已托寄/待回音 |
| 承接寻回失货 | 真实契约名称进入日志，未误写成当前浏览的护送委托 |
| 招募熟练水手 | 银两2370→2325，人数38→39，空额22→21 |
| 右舷齐射 | 余量12→11，出现装填状态与反馈 |

补充VM核验：超过市场最大数量的买入、超库存卖出均拒绝；两份委托可并存且去重；自定义家书含换行可回读；全部存档状态恢复；船员与舰船渲染在多组资源/状态下通过。上述为UI演示合同，非Godot战斗、海水或物理运行测试。
