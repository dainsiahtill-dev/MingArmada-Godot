## 236个有效状态与45个默认别名

原目录的281项声明状态经严格复核后，保留 **236个有效特殊状态**，另有 **45项默认别名**。别名与正常界面在业务意义上相同，已从重复状态截图目标中删除，并保存在各页面的 `defaultStateAliases`，以便追溯旧名称。

状态比较排除了通用说明条、审阅壳状态提示和页头标题，实际比较正文、控件值／禁用、图像与绘图内容。仅更换一条情境说明不再视为状态完成。市场缺货、货位不足、待交验、短损争议、寄款回读、外交授权边界、失败恢复、任务固定结果等必须在正文或操作上体现差异。

特殊状态允许派生只读界面样例，但不能写回真实资源或业务记录。样例注明来源和限制，虚拟寄件不能扣银，虚拟检查点不能加载，委托“提交待验”不能冒称对方验收并发报酬。真实寄件、真实pending委托与真实快照优先。固定剧情结果与未证实的史料边界也不会变成可付费消除的选项。

## 本轮交付边界

交付内容是完整的可点击网页UI原型、状态画册、采用美术及出处、制作需求预算、自动合同证据与浏览器截图。买卖、汇银、寄信、订造与存档均是当前网页会话内的模拟，不对外付款、发送真实信件或改写Godot个人存档；刷新或关闭页面会失去内存演示状态。

Godot路由与正式状态读写、完整43场战役接入、航行物理、海战AI、音频、GPU、性能与长时资源释放仍须独立实施和验证。史实节点、文学化对白、原创人物与虚构战事的边界以[唯一剧本](../../narrative/zheng-zhilong-story.json)的历史级别和说明为准，不以原型演示改写既定生涯结果。
