## 交互与数据边界

- 六港详情及航行目标由 `destination` 驱动。海图上港口通过 `open` 设置目的地后进入详情，顶部港口按钮可留在海图选择；沿岸路线按目的港使用不同路径。
- 篇章使用真实六幕与43场数据。简报、对白、史注读取当前选择；对白推进在末句停止，不循环回开头。
- 设置使用现有 `data-setting`。恢复默认由共享 `settings-reset` 执行。网页设置不修改操作系统音量、窗口或 Godot 偏好；相关选项用于本次会话的交互与样张。
- 出港使用共享 `route-confirm`，沿岸至少80、直航至少110粮水；不足时页面禁用，处理器也会拒绝。确认记录后进入航行页并由共享通知反馈。
- 实验室选课使用 `open labTopic`；三课题有独立资料与图解。已登记的历史实验记录不是本轮重新运行证据，网页不能启动原生实验或填造 GPU 性能数据。
- 状态预览只派生本地副本。样例存档、资源条件、天气和情境不写入真实会话状态；审阅层已标明其为预览。退出该状态后恢复正常数据。
- 估计航日、趋势曲线和示意海图用于界面判断。它们没有接入航程模拟或实测海况。
