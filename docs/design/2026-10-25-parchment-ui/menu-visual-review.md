# 菜单与恢复界面视觉复核

日期：2026-10-25。只读复核 `evidence/gpu-menu-r3/`。本次逐张通过 `view_image` 以原始分辨率直接打开全部 11 张 PNG，并读取 `capture-result.json`；未改产品代码，未运行 GPU 或测试。

## 结论

这 11 个已捕获状态没有发现阻断交付的缺字、文字叠压、深灰漏肤、内容越界或焦点不可见问题。纸面留白已生效，嵌入式文件窗口顶栏纸底完整遮住后方恢复页标题。正文深墨与浅纸、主操作浅字与朱砂之间可肉眼辨识，风格与主背景一致。

存在一项非阻断的文案一致性细节：嵌入 FileDialog 中 Godot 内建 `Path`、`Favorites`、`Recent`、`Directories & Files`、`File` 仍为英文。窗口标题、文件过滤说明、主要确认和取消按钮已中文化；本次不扩大到内建控件翻译或业务改动。

## 证明范围和限制

- 直接看到的是上述 11 个静态 GPU 帧；本次没有观察连续动效、滚轮连续滚动、键盘 Tab 全程、鼠标穿透或拖动窗口过程。
- 截图说明已覆盖的 focus、下拉与模态状态视觉清楚；完整输入行为仍以捕获器记录和行为回归为据。
- 320 图只覆盖首页，不证明 320 宽设置/恢复/文件窗口可完整使用。设置在本组覆盖 1600×900 与 1280×720；恢复/文件窗口覆盖 1280×720。
- FileDialog 是 Godot 嵌入窗口；没有原生操作系统文件窗口、导出保存覆盖确认、实际文件导入成功或所有目录视图的图像证据。
- 对比结论是原图视觉审查，没有测量整张纹理上的逐像素 WCAG 最低对比值，也未覆盖系统高对比模式、全部 DPI 与色觉差异。
- 不涉及正式游戏连续海面、帧率、完整航程或导出包验收。
