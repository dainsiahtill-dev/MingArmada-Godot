# 旧版航程视觉复核

日期：2026-10-25。只读复核 `evidence/gpu-legacy-r1/`；全部 8 张 PNG 均通过 `view_image` 原始分辨率直接打开。已读取 `capture-result.json` 中动作、截图、断言、错误与存档保护结果。未修改产品、未运行 GPU 或测试。

## 结论与需修项

已捕获的市场、海图、存档、设置页均应用纸面与墨字，标题、按钮、标签、输入文字未见缺字、叠压或水平越界；世界画面仍留在面板之外，没有被全屏纸纹遮盖。

**发现一项共享控件样式遗漏：SpinBox 上下调节箭头仍为默认浅白色，浅纸上对比不足。**

- `legacy-market-1600.png`：粮食、木材“交易数量”输入右侧，约 x=1562，白色上下箭头很淡。
- `legacy-market-1280.png`：同类交易数量控件，约 x=1242，同样问题。
- `legacy-settings-1600.png`：音乐音量、音效音量输入右侧同样是浅白上下箭头。
- `legacy-settings-1280.png`：画面底部音乐音量输入右侧可直接看到此现象。

数值墨字仍清楚，主操作没有因此不可用；但该控件尚未完整适配纸色。建议由共享主题负责人统一替换 SpinBox 的上下箭头为墨色资源，保留数值与输入行为，再捕获受影响状态确认。已将具体图片与位置反馈 root；本复核不擅改共享文件。
