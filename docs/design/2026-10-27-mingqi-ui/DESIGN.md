# 正式航程 UI：透明素材与轻量信息板

2026-10-27，用户要求继续打磨游戏界面，并明确希望许多 UI 用生图模型生成透明 PNG 组装。延续项目最新明代海疆绘卷方向：纸白、青绿、靛青、旧金和少量朱砂；以正式明旗航程为本轮入口。

当前真实 1600/1280 基准见 `docs/design/2026-10-25-parchment-ui/evidence/mingqi-20261027-baseline`：左上常驻纸板约 430×470，4 行操船提示始终占用海面；页面已使用共享纸纹，但缺少更有层次的独立透明美术组件。图为实际 GPU，非持续航行/FPS验收。

生图组件优先作为可复用的独立透明美术层，不把文字、数字、按钮状态或业务内容烘焙到图片中。规划：航海信息牌、操作按钮底、航海纹饰；按生成结果决定实际可用组件及切片方式，留原始 alpha、真实提示词与原图，不假称未用组件已接入。所有装饰 `MOUSE_FILTER_IGNORE`，保证操作面板、状态、焦点、工具提示与世界点击可用；禁用/悬停状态保持清晰。允许复用现有主题，禁止用静态整屏截图代替实时游戏。

航程的完整操船提示仍可按需打开，默认收起以减少视线遮挡；重建快照时保留展开状态，所有按钮、存档、时间、信号和真实意图合同保持不变。优先让 1600×900、1280×720 和窄窗口都能访问操作。无新表现/玩法算法，不修改世界、海图投影、船舶研究或用户数据。

验证：新的 UI 行为先红后绿；既有航程、输入、存档/弹窗回归；同一真实 MainScene GPU 入口截图对比，实际点击与窗口布局单独记录。独立存档 profile，确认原用户槽不受影响；静态图不代表连续海况/FPS。
