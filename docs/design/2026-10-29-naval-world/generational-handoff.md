# 一面旗，两代人：主角交棒与事业传承

- 文档 ID：`zheng-family-handoff-20261029`；版本：0.1；日期：2026-10-29。
- 用户确定：郑芝龙、郑成功双主角贯穿主线，阶段故事带玩家体验不同玩法。主笔选择1646年前后的父子分途作为交棒段，具体史实按[生平核查](../../research/2026-10-29-zheng-chenggong/life-and-narrative-boundaries.md)修订。
- 状态：原创玩法与叙事设计，未实现、未运行。配套[24章主线](dual-protagonist-campaign.md)和[总纲](WORLD-AND-GAMEPLAY.md)。

## 1. 交棒要保住的体验

郑芝龙篇让玩家从谋生者成长为能影响海路的人。郑成功篇面对的不是一张空地图，而是父亲留下的船、旧部、商路、恩怨与承诺；他要决定如何使用这些力量，以及哪些旧做法需要改变。

换主角不清空玩家此前投入，也不把父亲全部人船与本领无条件复制给儿子。交棒前展示哪些能交接、哪些须谈、哪些受历史局势影响；交棒后第一趟航程尽快让玩家感到“过去做过的事仍然有用”。

故事模式以已核重大历史转折为骨架，玩家控制撤离、留守、供给、求援和具体人物的去向。不能提供“改变父亲重大历史选择”的假按钮，最后却让任何选择都无提示归零。若以后开放彻底改变重大史实的分支，作为明确的架空规则另设计，不偷偷混入历史纪事。

## 2. 同一世界，两名独立人物

| 层 | 交棒处理 | 玩家能够理解的原因 |
|---|---|---|
| 当前主角 | 从郑芝龙换为郑成功，分别保留生平、年龄依据、经历与个人专长 | 儿子不是父亲换名字；父亲出生年份存在讨论，不强锁未经核定年龄 |
| 世界历程 | 港口、战争、货流、组织、已完成事件和损失连续 | 世界不会因为镜头转给儿子就重置海盗、供给和悬赏 |
| 航路知识 | 亲历知识属于当事人；能写入海图、船册或经人传授的知识可交接，并保留时效 | 玩家本人记得，不代表新角色自动取得所有秘密地图 |
| 人物关系 | 每个同伴分别记与父亲、儿子的关系，以及对家业的态度 | 追随父亲的人可以信任儿子、观望、另谋出路或只愿做一航次 |
| 船只与物资 | 依据私人、家业、合伙、公产、租借和战利品等归属逐项处理 | 交出指挥权不等于取得产权，借船必须有原约或新的同意 |
| 个人能力 | 父亲本人精通的刀术、操船习惯留在本人；训练过的团队、教习与已建立的流程可延续 | 玩家不会丢掉全部经营成果，儿子仍有自己的成长和新专长 |
| 名声与榜单 | 父亲个人功业进入其传记；组织实际实力按交接后资产更新，儿子建立个人声名 | 不把父亲全部悬赏和军功机械转抄为儿子的罪与功 |
| 未完契约 | 保留履行主体、担保者、货主和可交接范围，取得同意才更换负责人 | 商人可以继续信任家业，也能要求重新议约；不能父子切换即消债 |

公开关系中可以出现“念你父亲救过我，先替你带这一趟”，同时本人对郑成功仍持观望。这样的有限援助比全员忠诚条直接满格更能让玩家感到两代人的联系。

## 3. 父篇最后两章：主动筹备，明确得失

### CH-11：把能带走的先送走

玩家收到彼此不一致的军情和会面消息；真实历史人物的立场与具体时序须遵来源，微观任务属于创作。玩法聚焦短期调配：将伤船送修、把一批民用粮与药先送到可靠港、安排家属和伤员转运、给远航船长发出可送达的指令。

准备不会凭空撤出所有资产。送人要占船和航期，先保船可能错过一些货；高手可以通过预先培养的副手、修护班与可靠商路保住更多。失去某一项也要有继续路径，不把之前几十次航行全部判作无效。

章节末展示一份简短的“已确认／待确认／无法带走”清单。只有主角和联系人实际知道的消息被显示；尚未回信的分舰队标最后报告，不能提前宣判叛变或死亡。

### CH-12：父子分途

镜头和叙事重心从郑芝龙的决定转向郑成功的处境。历史骨架不由一次装备购买决定；玩家在这一章实际操作的是最后一段护送、接回散员、安排船队和交接信息，不是观看一长段过场后被清空存档。

交棒前有自动保留的章节记录，分别存父篇结算和子篇初态，重复载入不能再次发钱、复制船或复活人。人物消息、物资去向与没能兑现的承诺进入日志；旧世界中仍活跃的父辈同伴有真实位置和可追索的后续。

## 4. 子篇开头：用旧积累完成一件新事情

### CH-13：不是从零开始

先给郑成功一个短而真实的目标：把分散人船带回一个可用的集合点，筹出下一航次的工资和食水。原先善待过的匠师可以接受部分延期，商人可能提供有上限的货单，曾被弃援者可能拒绝帮忙。所有帮助都指向具体提供者和资源。

新的主角能接手基本操船与指挥，不重做一整套初学教程；只用一次可跳过的练习展示与父亲不同的专长或指挥习惯。已经会的贸易、护镖、侦察与修护马上用于重组，不强迫先刷等级才允许操作自己的船。

### CH-14及以后：重新赢得同伴的决定

后续征讨、守港与贸易让旧部看到郑成功怎样处理责任。有人由临时护送转为长期追随，有人只愿保持商路伙伴，有人带着自己的船离开。可通过事件和谈话改变关系，不以一次赠礼抵消父辈旧怨。

二十四英雄专长与三十六职业继续适用，但此前十二位具名英雄按子篇约1650阶段设定：未核年龄前不让同一位青年在1620年代以相同年龄出现。父篇可使用按出生和在世时段生成的普通骨干、原创父辈人物或已核历史人物；继任者、子弟和同名者必须有不同身份。

## 5. 三个具体传承例子

**一条修过三次的船。**父篇用它护送过商货，也在一次接舷中损坏过舵。交棒时船属于家业、在可交接地点、能由愿同行的船员开走，便带着原名、损伤、改装和航海记录交给子篇；若尚在远港大修，则先收到报告，之后完成真实提船。不能把回忆动画里的旧船当成第二艘奖励船。

**一位始终不肯签长约的庖师。**他感激郑芝龙付清工钱，却只答应替年轻人管一趟伙食。子篇中玩家若在紧缺时仍保证伤员配给，他可能介绍徒弟长期留下，自己回港开饭棚。船员能力因教习和师承延续；本人退休后不再给旗舰提供虚空伙食加成。

**一支在外经营的船队。**旧舰长持两艘家业借船，自己另有一艘。接到交棒消息前继续履行旧约；消息送达后可带借船返航、议新约或清算离去，自有船仍归他。子篇玩家可以把他当盟友，而不是因新主角出现就自动没收所有船。

## 6. 阶段教学的共同规则

每次首次引入新玩法，最多增加一项主要决策，其余由已有预案或同伴代管；接下来用不同目标再次出现，最终在台湾战役合用。角色成长允许主线与自由委托交错，不把贸易、庖师、乐师等只留在教程里。

| 前段学到的能力 | 中段变式 | 台湾战役中的用途 |
|---|---|---|
| 劫掠与夺船 | 识别高值目标、保存货物、管理押船人手 | 截断敌方补给、追击特定目标，抢船不等于抢到全部物资 |
| 贸易与经营 | 不同港口、军需订单、远航周转、危机供给 | 筹粮筹船、维持长期围城和修造，战损会反过来影响贸易 |
| 护镖与救援 | 慢船编队、分批过口、断信预案、伤船拖带 | 渡海运输、登陆补给、援军来袭时护住己方海路 |
| 港口保卫 | 岸海协同、损管、预备队、居民通行 | 保护登陆场与后方，抵御外援、保住可用码头和船坞 |
| 征讨与登陆 | 侦察、两面牵制、夺岸点、驻撤与交接 | 区分两座堡城与外围据点，多阶段争取谈判条件 |
| 船员与英雄 | 实际岗位效果、成长、授权分舰队、关系处理 | 同时处理海上、岸上、运输、修护与伤员；主角无法亲自控制每处 |

完成主线某章只证明接触过玩法，不自动把全部同类技能升满。高熟练玩家可采用等效策略跳过重复教学，但必须产生该章要求的真实目标结果。

## 7. 历史与玩家结果

重大人物经历、受抚对象和政权必须准确区分：1628明朝受抚与郑芝龙对应；郑成功面对的清廷招降另属不同事件，不能为了让两个主角走同一路线而互换。沿海海盗、倭寇、地方武装、正规水师分别记名；没有依据不把任何沿海敌人统称倭寇。

普通关卡允许成功、部分成功、撤退和失败；历史主线的下一章可根据局部结果改变资源、人物与任务，但不能一句旁白把已失败目标说成成功。关键历史节点若必须达到某个条件，可提供重整、补给、另路达成或明确的战役重试，而非隐形强制获胜。

台湾战役的史实日期、登陆地点争议、普罗民遮与热兰遮、增援和谈降按[专项研究](../../research/2026-10-29-zheng-chenggong/taiwan-campaign-phases.md)确定。世界地图也要按章节时段呈现，例如父篇早期平户、子篇1650后的平户环境不同；不能把同一港口静态规则套四十年。

## 8. 章节、跳年与检查点的最低合同

每章制作前记录当前主角、日期精度、世界时段、已发生的历史事实、玩家可改变的局部结果、进入条件、完成条件、保损恢复路线及检查点恢复范围。入章条件只依真实可用人船与事件，不能因人物卡已解锁便假设其在场。

主角在普通战斗中受到致命失败时，进入该章失败流程，不一边登记历史人物已阵亡、一边让其继续发表后章对白。普通英雄、首领和船员的确认死亡仍在当前存档持续，不能为了补齐台词自动复活。

跨年是有说明的章节过渡：先结束或明确续签正在履行的航次、合同与远队任务，展示休整／有限经营摘要及资产变化，再进入下一日期。它不是后台高速运行几十年口粮与工资，也不是把旧债、伤势和关系清空。摘要中的收入、修造和招募仍有有限预算与来源；玩家选择继续当前年份的自由航次时，不提前播放下一历史阶段。具体日级推进与章节日历如何共用权威时钟，留待实现审计，不能各自暗改同一日期。

检查点重试与保损继续分开：保损继续使用当前世界的伤亡、库存和债务；检查点重试明确恢复到某一章／阶段保存的整份状态，同时回退其后的结算。禁止从旧快照恢复船和粮，却保留失败后取得的赏金或世界事件。架空续航及返回史传是未来独立方案，不作为当前总败后已存在的出口。

| 交棒夹具 | 输入事实 | 应有结果／禁止的伪结果 |
|---|---|---|
| 家业船已在集合点 | 产权明确、船员同意、船可航 | 原船ID转入儿子可指挥集合，保留损伤和配置；不另发一艘同名满血船 |
| 借船仍在远港 | 原租约、报信未达、外队正在交货 | 标最后消息和待交接，外队按原约行动；不立即算儿子在场兵力 |
| 公船随原部队离去 | 没有正式调拨或新的使用资格 | 不能直接继承；可通过新的军务或交涉取得后续使用权 |
| 老伙伴拒绝长期追随 | 信任父亲、未信任儿子，但愿完成当前一航次 | 只提供约定的一航次服务，个人船仍归本人；不强制永久忠诚或判叛变 |
| 父亲私人债与家业债并存 | 各有明确借款主体、担保和账目 | 逐笔处理可交接责任，亲属关系本身不清债也不自动令儿子承担所有私人债 |
| 主要舰船损失 | 仍有人、可联系盟友及可执行承运机会 | 子篇从有成本的租船／受雇恢复，不发更大免费舰；若无可行恢复则明确章节重试 |
| 重复载入交棒 | 同一父篇结算已执行 | 读取同一子篇初态，不重复移资、发奖、改关系或生成人物 |
| 年代不合的人物／设施 | 未来才出生的英雄，或当章尚未建成的堡垒 | 拒绝作为既有实体入章；可换普通人物／合法时段，不能靠换显示名掩盖穿越 |

## 9. 实现前必须验证的内容

1. 单一世界内父子有不同人物身份；交棒不复制人物、船、货、账或奖励。
2. 人员关系、公产、私人财产、家业和合伙资产按既定归属交接；未送达的命令不视为违约。
3. 部分损失与未归船仍能进入有资源来源的子篇恢复路径，不以免费大舰抵销父篇失败。
4. 初次玩法、变式和最终应用能从章节表逐项追溯；不会进入攻台后才第一次要求玩家理解运输与长期补给。
5. 首章、交棒、攻台准备与最终结算都必须从真实入口运行；按不同存档覆盖跳过支线、同伴缺席、首领死亡、旧账未结等情况。
6. 1650旧试玩另存，保留原证据，不静默改名、改出生年或把旧青年经历嫁接为史实人物。新主线存档和旧存档兼容方案须在生产审计后再定。

当前只有设计与史料研究；新主角入口、章节、转场、角色模型、对白、存档及战役均未通过运行验收。
