# 江海好汉：英雄、同伴与自立船队

- 文档 ID：`naval-world-heroes-companions-20261029`；版本：0.1；日期：2026-10-29。
- 状态：**原创玩法设计，未实现、未运行、未验证平衡；人物与示例均为虚构。** “英雄”指有经历、有独门本领的人，不是史料所证的超人或稀有度等级。
- 上位约定：[世界与玩法总纲](WORLD-AND-GAMEPLAY.md)、[生涯、势力与经济](careers-factions-and-economy.md)；普通岗位见[船员职业与船上生活](crew-professions-and-shipboard-life.md)。沿用默认单机、20船舶配置、10种生涯、8张世界榜；主线现为父子双主角，原1650／厦门入口仅作旧试玩基线。英雄按在世年代进入对应篇章，不另造免费资源或独立刷分榜。
- 用户明确：客栈可随机遇到多种本领的英雄，招为同伴，日后能让其独自发展、带领船队。下文人数、合同、成长和交互细则是主笔建议，尚待玩法确认。

## 1. 选择：认识一个人，改变一种做事办法

同一个英雄可以从船上伙伴成为军官、舰长、分舰队长，最后成为合伙船主。最值得记住的是“他为什么跟我出海、帮我做成什么、后来为何另走一条路”，不只是战力高低。

| 备选 | 所得与代价 | 本稿选择 |
|---|---|---|
| 英雄卡牌与全队被动加成 | 容易收集；人物变成装备，岗位和人力失去意义 | 不采用为核心 |
| 每位英雄均需玩家直接操控 | 动作表现强；与旗舰和小队指挥争夺操作 | 暂不扩成第三人称动作 RPG |
| 持续人物、具体行动、意图授权 | 与船员、市场、关系和舰队同处一世界；需要可靠状态与消息系统 | 推荐；先验证少量完整人物，再扩充内容 |

英雄带来**新行动、不同准备方式或新的协商对象**，也可以有明确、可验证的数值优势，例如更快完成一次备射、更熟练地控制材料损耗。普通船员仍能训练完成基础操船、游水、作战、维修、指挥与贸易；英雄擅长组织某种复杂做法，须有船、工具、队员和窗口，不能靠一个人替代整支队伍。已教会普通人员的技能保留，离队不让整船忘记如何航行。

英雄是身份与经历，不是职业白名单。名庖师、知名乐师、巧匠也可在客栈招募：庖师用真实食材组织返航庆功餐、改善恢复与同桌关系，缺粮时要在口味、储备和公平分配间选择；乐师用合练的曲目稳定休憩节奏或鼓舞出航，需合适场合、休息与队员参与，警戒静默时不能强奏。基础做饭、演奏与修船人人可从普通岗位成长获得，英雄故事和招牌行为另赋个性；水手不会因没有英雄而不能吃饭或补船。

## 2. 人物的唯一身份与客栈相遇

**HERO-SYS-01 人物连续性。** 每人有稳定 `hero_id`、出身、专长、经历、关系、资产、当前地点／行程、身体状态、合同与唯一当前岗位。具名剧情人物先登记身份；生成器不得复制其模板身份。随机人物在首次进入世界时生成并保存，换名、换港、换阵营仍是同一人；退出客栈不销毁，不被招募也会受雇、候船、回乡或离港。

**HERO-SYS-02 客栈招募。** 随机性决定谁因何事来到这里，不决定玩家抽到什么颜色的英雄。候选来自当地持续人物与真实抵港人物；新增人口来自预设地域与事件人口预算，须有可解释的迁入来源。没有实际需求的客栈可以暂时没有可招募者。

| 相遇阶段 | 玩家所见与可做的事 | 条件、成本与失败出口 |
|---|---|---|
| 听到传闻 | 船夫说有人懂浅道、掌柜记得落难镖师；花时间打听或请熟人引荐 | 标出消息来源、听闻时间和最后去向；传闻可能过期，不直接揭露当前坐标 |
| 在场相见 | 看见修索、争账、等家书的人，谈经历、手艺和为何不出海 | 海域、港口行业、战争／船难／封锁事件改变来客分布；高声名带来慕名者，也带来戒心和竞争雇主 |
| 核验本领 | 共同短途出航、带人救船、比对货账、让同行作证 | 付试工工资和材料；有明确中止条件，不能用必胜表演掩盖伤病或履历不实 |
| 谈条件 | 商议工资、分成、职责、航区、家人安置、旧债或救人承诺 | 要求能由不同方式解决：赎债、作保、做一次同行任务或等其完成私事；不是统一交钱招募 |
| 试航与加入 | 有期限的试航合同，双方都可在约定港终止 | 试航期间真实占人、领饷、受伤；不满意可清算离开，已支付劳动不全额退回 |
| 未能招到 | 记下人物和关系，追随新线索，或以后合作 | 拒绝与拖延可能使其另投船主，但不会按一次拒绝永久锁死；别人的合同和航期不能被玩家召唤打断 |

客栈候选随**游戏时间、行程和世界事件**变化；开关界面、进出店门、暂停或读同一存档不重掷候选、诉求与本领。等待明确消耗时间、粮饷和合同期限，提前显示后果。新事件可改变机会，但战败不触发“补偿式生成更强英雄”，付钱请客也不无限刷新人物池。

适配例：河口常见引航者与水性好手，船坞港常见匠师，远航港有通事与账房；征调使退伍者等待新差，风灾使修护人员忙于救援。分布是倾向，不限制某类人物永远只能在一地出现；人物迁移和已有关系优先于抽样权重。

## 3. 二十四种专长：改变行动，留下应对空间

`HERO-ROLE` 是专长 ID，不是互斥职业。首轮建议每人一个主专长、一个有经历支持的辅专长；不可无成本叠齐全表。下列均为原创游戏行动，数值、动画与 AI 尚未实验；火器、工艺、水下行为不提供现实操作教程。

| 稳定 ID／专长 | 能够新增的行动与有效条件 | 占用、代价与敌方反制 |
|---|---|---|
| **HERO-ROLE-01 破阵刀客** | 已有落脚点且甲板较宽时，率突击组短程冲开一段守线，为后队占位 | 占战兵、体力与撤路；狭道、长兵阵和侧击能截断冲势，不能一击清甲板 |
| **HERO-ROLE-02 盾舷老兵** | 把相邻队员组织成移动遮护，掩护伤员或射手跨过一段暴露通道 | 下降移动与还击能力；上下层夹射、绕侧与路线阻塞能拆散队形 |
| **HERO-ROLE-03 接舷好手** | 争得已存在的连接点后，调度小队分批上船、保留一条回撤通路 | 要连接设施和守点人员；敌人可反夺、切断或逼双方脱离，不能凭专长凭空连船 |
| **HERO-ROLE-04 快铳射手** | 在已观察射界内指挥一组射手轮换射击，压住指定暴露岗位 | 要队员、弹药和准备时间；遮护、烟障、换面与突进使目标窗口消失，不自动点杀船长 |
| **HERO-ROLE-05 弓弩教头** | 把若干射手分成轮替组，选择掩护登船通道或封锁一块甲板 | 保留射界与预备组，减少同时输出；敌人换路、贴舷或迫使转向可解除压制 |
| **HERO-ROLE-06 望海斥候** | 乘轻艇／占高位辨认航迹、护航间隙与疑似诱饵，再带回有来源的观察 | 占艇、人和航时；遮挡、伪装、天气与敌哨造成不确定，不能透视岛岸或读隐藏货舱 |
| **HERO-ROLE-07 识潮领航** | 核验本地潮道，提出候潮、减载或换驳方案，使小船利用另一条通路 | 需当地经历与新观察；陌生河道、变化浅滩和封锁点使旧经验失效，误判可搁浅 |
| **HERO-ROLE-08 操帆领班** | 带操船班提前准备一次受限转向／收放帆转换，协调两船先后过狭口 | 占用操船人数与准备阶段；受损索具、突变风况、敌压制可迫其中止，不能逆风瞬移 |
| **HERO-ROLE-09 桨队头领** | 组织桨手轮替，保留一段突围或接应能力，并向玩家报可持续程度 | 桨手仍消耗体力、粮水和岗位；长追击、障碍和桨位受损会耗尽预备力 |
| **HERO-ROLE-10 踏浪水客** | 在受支持的浅近水区域短暂隐蔽接近、观察舷边、尝试从可攀点登船，或接回落水者 | 见第 4 节；需要接应与恢复，目标守望、舷高、海况、无攀点均能阻止，不能无限潜伏 |
| **HERO-ROLE-11 救生艇长** | 根据落水分布安排接人次序，指挥救艇与拖船在容量内接续转运 | 占用艇、队员和危险水域时间；敌追击、容量不足与恶劣海况可迫放弃，救人不自动获船权 |
| **HERO-ROLE-12 舱面修护师** | 诊断局部故障，选择临时封闭作业区、拆备件保操船或等待入坞 | 用材料、工时与修护班；封区影响通行和货舱，敌持续打击可使修护失效，临修不等于全新 |
| **HERO-ROLE-13 舰具匠师** | 评估既有船体，提出可试制的特色舰具、遮护或岗位改装方案 | 要图样来源、适配位置、坞期、材料与训练；采购中断、重量和射界冲突限制方案，不会海上瞬造 |
| **HERO-ROLE-14 随船医者** | 战后分诊、安排疗养／转港，令可恢复人员有不同复岗路径 | 用照护人手、药材与航时；延误、再次负伤和药材短缺恶化伤情，不能复活或战中瞬间满员 |
| **HERO-ROLE-15 行商经纪** | 汇集多个真实订单，提出分港交货、回程配载或联合承运 | 各段都受货物、买方资金、期限和佣金约束；竞争到货压价，承运失约追责，不能固定稳赚 |
| **HERO-ROLE-16 清账先生** | 对照货单、分成和实物发现亏空，提出预留工资、分期清算或争议仲裁 | 需取得账簿、证人和查验时间；隐瞒货单会留下未知项，熟人包庇可引冲突，不直接透视真相 |
| **HERO-ROLE-17 港口通事** | 引荐当地可接触者，解释通行条件，组织赎俘、补偿或共同承运谈判 | 需要语言／地方关系和对方意愿；担保可能损害本人信用，敌对法令不因高魅力自动失效 |
| **HERO-ROLE-18 市井耳目** | 经营有具体人物的线人关系，交叉核验某条航迹或争取一次提前报信 | 花佣金、时间与信任，消息有时效；假线索、断联和线人拒绝使情报不全，不能全图常亮 |
| **HERO-ROLE-19 旗鼓参谋** | 在可通信范围内组织信号与预设应变：前队失联则后队守口、救艇前出 | 占旗鼓／瞭望岗位和训练；烟障、距离、误识与传令船损失使命令延迟，不能远程同步全舰 |
| **HERO-ROLE-20 分队将才** | 统筹有限舰数执行护航、诱离或撤退，遇约定条件在数个预案间选择 | 要舰长和补给，扩大规模增加协调负担；敌分进、断信与任务冲突能拆散计划，不免费增加每舰战力 |
| **HERO-ROLE-21 习艺教习** | 在港训练替补岗位或传授已掌握的协同动作，让普通人员能承担一次新职责 | 占师徒、训练时间、工资与器具；疲劳和频繁离港延误课程，不凭重复菜单无穷加经验 |
| **HERO-ROLE-22 粮台掌事** | 为多船制定分段补给和紧急配给，协调仓点与运粮船应对一条线断供 | 需真实粮、水、仓位与承运者；敌袭、腐损、征用和居民需求可挤掉余量，不能无限凭空补给 |
| **HERO-ROLE-23 名庖师** | 按真实食材组织长航餐、伤员适口餐或故乡席，提高相应恢复／士气效果；用共享饭食调解分配争执，触发寻食材、授徒与故乡约定 | 占厨房、助手、食材与工时；缺水、受潮、航程延误或偏袒少数会削弱效果并引争执；丰盛宴席减少后续储备，不能一餐消除欠饷和伤病 |
| **HERO-ROLE-24 知音乐师** | 合练出航曲、归航慰劳或追悼曲，在合适场合直接改善士气与恢复氛围；记住各地曲目可打开同乡交往、传艺和遗愿故事 | 占本人岗位、排练／休息时间与乐器维护；警戒静默、疲劳、文化冲突或强迫欢庆可使表演中止或适得其反，不能替代粮饷、指挥通信与治疗 |

专长应形成合作：斥候找到目标，水客核验舷侧，盾兵保落脚点，接舷手带队，参谋留接应船。缺少一环仍可能另选正规接舷、谈判或放弃；不能把每次任务锁成“必须抽到某英雄”。同类专长也可因出身、师承、工具和关系形成不同方案，差异须能讲清代价。

普通庖师、乐师已有做饭、恢复与士气的基础效果；英雄提供更强熟练度、更多菜单／活动组织和个人关系事件。增益来自实际工作、消耗与参与者，不是人在名册就全舰生效；已获得的鼓舞按事件影响逐渐消退，不能跨海无限叠加。具体增幅、持续时间与上限须实验，默认静音仍以人物反应、曲目文字和状态变化表达效果。

## 4. 水性英雄：能见的冒险，不是潜水夺舰按钮

**HERO-SYS-03 水上隐蔽行动。** 首轮建议只支持有接应的浅近水、明确范围与可返回路径。水深区域、可攀位置、舷高、浪况、体力／气息、伤病、携带负担、己方接应与敌方观察共同决定“可试／危险／不可行”；具体门槛留给实验，不冒充现实潜水能力。

玩家选择“核验靠近侧”“尝试取得一个落脚点”“救回指定落水者”与中止条件。英雄自动执行可见的**准备、入水、受限隐蔽移动、观察、攀登／接应、返回恢复**状态；不要求玩家逐秒控制呼吸。气息与体力独立耗用，恢复要占时间和安全位置，反复上下水不能瞬间清空疲劳。

水下状态不能提供敌舰内部视野；登船点须先发现或靠近观察确认。目标航行状态变化、舷高不适配、可攀位置被遮断或失去接应时，计划必须重评，禁止贴在船外随船无限拖行。开阔外海、过深水域或超范围目标首轮直接不可用，仍可由救艇和正常接舷解决。

敌守望有视线与警戒状态，水面扰动、攀登与停留会增加被发现机会；守兵可以转看舷侧、封住落脚点、警告附近舰艇。英雄不能无声自动消灭全体守军。登上甲板仅占一个可争夺位置，后续服从双向接舷、小队人数与控制区域规则；夺船、押船、开船仍须足够普通人员。

遇阻可返回、请求救艇或在已可达位置等待；失联后只显示最后目击与可能范围。被发现可受伤、被俘或阵亡，救援有实际航程和容量。界面先显风险原因与撤回条件；危险增加时依据既定中止规则执行，不能在无消息可达时等待玩家远程点确认。此节是虚构游戏状态设计，不是现实水下作业或破坏方法。

## 5. 同一个人，从伙伴到合伙船主

**HERO-SYS-04 任职与授权。** 晋升不是升一级自动获船。必须有人选同意、适用能力／经历、可交接岗位、真实资产与签定权限；从近战好汉转舰长要学会管船管人，也可以一直做受尊重的伙伴。

| 身份 | 可自行决定 | 不包含的权力／变更条件 |
|---|---|---|
| 伙伴 | 接受当前任务，使用已分配工具，依中止条件保护自己与队员 | 不动公账、不自动号令全船；改派须走到岗位、交接工具 |
| 军官 | 管一类岗位与其分配人员，申请补给、安排轮班与已准训练 | 不抽空操船最低人数；跨岗位调人需舰长批准或既定应急规则 |
| 舰长 | 指挥一艘指定船，选择许可航区内的执行路线、补给港与避战方式 | 不擅卖、抵押借船，不擅宣战或超支；交接船长需在可接触处完成 |
| 授权分舰队长 | 在舰数、预算、任务与交战范围内分配各舰，补员、接准许的合同 | 不能侵占船员私财、无限扩舰或承诺玩家外交；越界计划先请求，未获许可按预案保全 |
| 半独立合伙人 | 经营自己的账与产权份额，在约定行业、海域和风险范围独立经营 | 有独立议价与退出权；玩家可撤回自己的授权／借产，不能单方没收其自有船或强命其参战 |

每人最多一个当前占用岗位和一个可定位实体；担任分舰队长时实际在某船指挥席，不能同时留在旗舰提供射击、训练或水性行动。长期资历、旧关系和已传授技术可以保留，正在进行的作用必须有在场执行者。任命队长占指挥席，原战斗岗位需他人接替；返港、登船、伤病停职都通过同一岗位交接。

**HERO-SYS-05 合同页。** 一页写明：任期与使命；船、人、工具的所有者；经费来源；工资与分红；常规开支与单笔上限；最低储备；活动海域；允许行业／交战对象；最多船数和人数；能否出售自有资产、购船、借款、转包；消息与报账港；禁止事项；召回、伤亡、继任、争议与退出规则。未授予项默认无权，不能用“自由发展”四字隐含全部授权。

**默认用模板完成派遣。** 提供商运、护航、救援、限定袭击与合伙开拓模板，预填任务所需的常规采购、工资、补员、维修、预算内交易与安全退路。玩家首屏选人、目标、实拨船人资金和风险档，确认一份含成本、分成、返还约定及主要禁令的摘要即可；完整条款放高级展开。借贷、额外宣战、处分共有船等高影响权限单列，选择后可保存为新模板。模板中已授予的日常经营不反复弹窗请示，不要求每派一名英雄填写几十项字段。

授权按职责逐项放开，规模升级需新合同和真实管理能力。委托方暂停某项新开支或新增合同，不撤销已合法对外签下的义务；修改分成只对双方同意后的新航次生效。英雄拒绝不合理新约可留任旧约至期满、降职回港或退出，不能自动判为叛乱。

## 6. 人、船、钱：能自立，也真的可能亏本

**HERO-SYS-06 资产与清算。** 玩家账户、分舰队公账、英雄个人账户、合伙经营账和雇主财产分别记录。经营主体、所有权、实际控制者和指挥者各有身份，不能因同一玩家控制就互相混作净赚。

| 资产来源 | 谁能使用和处分 | 损失与返还 |
|---|---|---|
| 玩家借出的船、货与周转金 | 英雄只有合同内使用／交易权；借船默认不能出售或抵押 | 归还同一船及应返货款；正常经营亏损由约定预算承担，故意违约另议责任，不无限扣英雄未来工资 |
| 英雄原有或用个人所得购置的船 | 归英雄；加入玩家舰队另签租用、雇佣或合伙条款 | 退出保有产权，欠款按明确担保处理；玩家不能用召回按钮变相没收 |
| 合伙账购置的船与仓货 | 依出资和合同记份额，日常指挥与出售权分开 | 退出按约估价、买断、分船或有序清算；借船不混作共有资产 |
| 公船、征用船与待裁定战利品 | 只按雇主／案件许可使用；缴获先登记控制，不立即变私产 | 返还、买断或裁定后才改产权；不能卖掉后仍在军籍或榜单重复计舰 |

分红基数为实际外部经营净收益：收入扣进货、工资、粮水、港费、维修、救助／赔付与约定公积后再分配，亏损无分红。内部拨款、借款、转移自有货和资产重估不是经营收入。售船所得先回所属资产账，出售收益单列，不把卖光船队当持续贸易成功。

船员各有实际身份、工资请求与服役合同。英雄可在授权范围与当地可用人力中招募，也能吸引愿意同行的熟人；转雇需本人同意与清算。接收玩家的老水手就从原船扣除，不生成副本；伤员、俘虏、旅客计载员与口粮，不自动计可战人员。工资不足先预警、缩小任务、返港协商或逐步离队，不能默许长期欠薪又满编运作。

**HERO-SYS-07 自主经营循环。** 英雄依意图查已知机会，核对船货与现金，选航路和合同，买补给／雇人，真实出航并遭遇事件，履约后记收益与损耗，再决定修船、储备、换船或扩大经营。离屏可以按航段批量计算，但船货、人物、航程和事件须与近场同一权威记录；切入海面不能补刷第二次结果。

独立发展至少能发生这些可追溯变化：赚取外部收入或赔掉本金；从有库存和产权的市场买卖／换船并等待交付；招到或失去船员；按自己的贡献取得声名；拒约、救人、结交或得罪当地人；反复履约形成航路与仓点；遭扣押、破产或退回受雇身份。不得凭空生成“发展成功的三艘大船”。

扩张受现金、最低储备、可买船只、船坞工时、港口准入、指挥人数、船员来源和合同舰数上限同时约束。默认不准借贷、不准把玩家借船抵押、不准任意开战；可授予有限借款额度与具体担保，玩家只承担明示责任。达到上限仍可提高既有航线可靠性，或请求扩大合伙，不能偷偷开无限子船队。

英雄可主动建议：独立跑一条回程线、买下一艘待修小船、与当地商人合股；也可因见不到利润而建议缩队。玩家设“保供优先”“净收益优先但不接赃货”“只袭指定敌方军需”等意图，不替他逐笔点买卖。每个结算给出航线、关键决定、对手、收入成本、人员资产变化与尚未履行的承诺。

## 7. 不用逐秒管理，但命令要来得及到

**HERO-SYS-08 决策与消息。** 战前设意图、预算、储备底线、可承受损失、禁令、返航触发和失联预案。常规执行自动完成；新增债务、扩大交战、出售共有船、越出许可海域、改变分利等重要决策必须提出请求，未经授权不实施。

近场靠可达的旗号、传令与会面，远处消息通过指定港、信船或已有联络航线传播。每条消息记录发出、最后转递、送达与内容时刻；界面明确“最后报告”，不把离屏英雄位置实时泄露。紧迫险情只能在信息能抵达时提前通知；无从及时请示时执行既定避战、保命、就近避港等预案，不能无代价瞬间问到玩家。

已知风险在派出前显示，途中新风险随消息报告；请求可在安全泊地等待，仍付食水与工资，超过事先约定等待期限则执行退路。通知按严重程度合并为航报，紧要到达可暂停游戏；同一缺粮原因不每秒弹窗。阅读、暂停和改界面不推进世界时间。

**HERO-SYS-09 召回与退伙。** 召回是一条带生效条件的命令：送达后停止接新单，按合同完成／解除在途义务，驶往会合港并交接。海上消息未达不视为抗命；系统显示预计通知窗口、最后确认处与待确认状态。真正执行违约需有已收令证据与原因，不能以“尚未回港”自动扣忠诚。

紧急撤权可向能联络的港口送达停付玩家账新授权支出的通知，并通知代管舰长；停付按消息送达生效，已在海上的船与人不会传送回来。玩家可派船寻访或援助，付实际航程与风险。半独立者退出需清算借船、债务与共同合同；自有财产随其离开，剩余关系可能支持再次合作，也可能形成竞争商路。

## 8. 信任、成长与落难

**HERO-SYS-10 关系与冲突。** 保存具体关系事实：谁救过谁、欠谁的钱、反对哪类委托、家人在何港、与哪名同伴有旧怨。信任可辅助判断，但履约可靠、个人亲近、价值冲突、对指挥能力的认可分别表达；不能送礼一次洗掉弃援与吞分红。

冲突按“私下说明诉求、正式提出异议、要求改约／换岗、准备退出、实际行动”升级。可见事项提前告知原因、期限和能采取的行动；隐情只能先给有来源的迹象，不让玩家全知。欠饷、攻打故乡或放弃救人可成为两难；同伴可以协商、拒绝该任务、请假、退出或另投他人，叛变不能只是隐藏好感突然归零。

**HERO-SYS-11 经历成长。** 航行、担任副手、师徒教学、负伤恢复、成功与失败形成履历，再解锁可选择的专长发展。例：水客可以专研救援、近水侦察或带队接应；晋为舰长需真实管理一次补给、工资与返航。相同低风险动作重复刷不等价于新经历，教学有师徒时间与岗位空缺。

成长可改变习惯与关系：败战后坚持留救艇，掌握账务后要求共同审账，救出旧敌后得到引荐但引起同乡反对。每段人物故事至少给两个能执行的选择及不同后果；没有“唯一正确选项自动加忠诚”，也不强迫每人最后成为全能舰队长。

**HERO-SYS-12 伤病、被俘与死亡。** 身体状态区分疲劳、受伤、疗养、失联、确认被俘、确认阵亡；未知不能直接结算死亡。伤病限制具体行动，可改任轻职责，但仍占对应岗位。照护、义肢／伤后适应若加入须另研究，不能用疗伤费用抹平所有长期经历。

被俘后保留同一人物、持有物和俘虏所在地的不确定信息，可谈赎、交换、法律交涉或发动游戏内救援；支付给持有人并发生实际移交才回队。英雄离岗由既定副手临时接管，能力和权限均有限；无合格替补则停工、避港或请求援助，不复制一个新英雄维持满效率。

英雄在规则明确的高风险战斗中可能阵亡，给出事件证据、纪念与财产／未付分成清算，已死者不换头像重新刷出。其自有船和合伙份额归约定继承者或暂存遗产账，玩家借产依原约收回，不因死亡将个人财产自动变成玩家战利品。默认普通失利仍优先提供负伤、逃脱、被俘等可继续结果，不强迫每次沉船死人；关键历史故事人物按模式约束另审，不以随机系统改写既有剧情。救援失败会留空缺与关系后果，世界不会送来更强替代者。

## 9. 四条完整人物路线

1. **林澈，河口水客（HERO-ROLE-10／11）**：厦门客栈等失踪兄长的消息，愿以一次救援试航换查找线索。斥候发现近岸受损商船，他确认可达位置后救回落水者，接应艇占去一处货位；目标加强舷侧警戒时，他选择撤回而非孤身夺船。玩家可按约寻找兄长，或赔偿延期并继续保供；兑现承诺后他愿教救生队，再租用玩家小艇经营救援。每笔救助费有船主支付，医药与拖修使某次任务亏损；后来用个人积蓄买艇，那艘艇属于他。玩家召回借艇须传信和交接，不能一并收走其自购艇。
2. **秦鹞，失势护镖人（HERO-ROLE-01／03）**：在岛链港因失船与前雇主争议，要求查清旧货单，不只要一笔招募金。试航与盾兵争下接舷落脚点，却因追击深入受伤；玩家选择留船接回他，会错过追货窗口。恢复后可带小队练撤退，再任玩家海沧舰舰长。升任分舰队长时限两船、保留工资储备，敌方诱追会触发护商优先预案。后来他请求袭击旧雇主，玩家可协助仲裁或拒绝越权；若拖延约定期限，他提出退伙，归还借舰并保留未结索赔，不突然化身满编敌军。
3. **沈知衡，船坞账房（HERO-ROLE-16／15）**：材料断供时在船坞港寻找愿承运木索的人，要求不侵吞工钱。清查货账让玩家少接一张看似高价却拖欠严重的订单，随后用两次真实履约建立信用。他以个人积蓄入股，与玩家签合伙经营账，买下一艘待修运输船；等坞期、招人、修船后才开航。竞争货抵港导致售价回落、一期亏损，他申请限额借款或卖货缩队。玩家拒贷仍可保留伙伴关系；两人商路稳定后获商业榜记录，集团内部转账不加榜分，同船不在两队重复计实力。
4. **顾望川，退伍旗官（HERO-ROLE-19／20）**：在军港等旧部抚恤结案，只愿先作军官，不立即卖身效忠。靠预设信号带运输队过狭口，断信时后队依约退到安全港；玩家收到的是稍后航报。获得两艘玩家借舰后独立护航，累计收入经审账再分红，个人份额用于买一艘确有卖方的小船。战事扩大时他拒接袭乡船队的委托，请求修改航区；玩家可改约、清算分手或坚持原约至到期。其船被俘后，替补只带幸存船避港；赎回本人不自动返还船货，救援与重建可能消耗旧利润。关系尚存可复职，清算退出也可成为有真实资产和旧交的竞争船长。

## 10. 界面、实验与接入边界

客栈用人物位置、短对话、未喝完的茶、等待的货票与同桌关系讲故事；青绿海疆、靛青、朱砂与象牙纸延续既定风格，克制旧金用于层级。主面板呈现“为何在此、本领能做什么、想得到什么、双方尚未说定什么”，无抽卡光柱、星级稀有度、商店礼包或满屏属性卡。

人物页先展示当前所在／最后消息、职责、正在做的事、近况与重要关系；契约、财产和履历按需展开。任命时读回岗位空缺、权限和成本；海图显示最后报告及消息年龄。战斗用人物标记、路径、动作阶段、被发现与中止原因保证默认静音也可读，装饰图不得替代真实文字与输入控件。

以下是拟研究课题，**尚未登记、无 Demo、全部未测**；实施前按[研究流程](../../research/README.md)与[课题模板](../../research/TOPIC_TEMPLATE.md)建正式报告、独立实验和目录条目，不能把本稿当集成证据。
