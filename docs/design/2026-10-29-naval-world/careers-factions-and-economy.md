## 1. 设计取舍与共同循环

本案选择“**同一片海、不同挣钱与结盟方式**”。商人运来的绳索能修护航舰；护航成功压低损失预期；海盗改劫军需会拖慢敌方造舰；夺港又改变税收、招工与补给。职业是持续做出的选择，不是创建角色时永久锁定的职业树。

| 候选方式 | 收益与代价 | 本案取舍 |
|---|---|---|
| 各职业独立任务线 | 易读、易控制节奏；贸易、战争、海盗互不产生后果 | 保留入门任务，不作为世界运行方式 |
| 一次性模拟所有商船与人口 | 因果细；计算、存档与调试负担大，玩家难辨后果 | 不作为首轮实现前提 |
| 有限航区、实体关键船队、港口批量供需 | 能见到自己影响的船与港，允许分阶段验证；需限制离屏结算与信息误差 | 推荐；机制仍须独立实验确认 |

共同循环：**获知机会 → 查货、查人、查海路 → 配船与补给 → 航行／交涉／战斗 → 救援与处置 → 回港履约 → 看见世界变化 → 再选生涯**。每次出航至少有一个非歼灭目标；每次回港至少能读到一条与本人行动有关的结果。

时间以游戏航程推进：航行、维修、训练、等待船期消耗时间；暂停与阅读账簿不偷偷推进库存、追捕或合同期限。选择“等三日”前显示到期合同、工资、封锁风险；跨海与近海不得按相同固定航时处理。下文所有周期都是待调参的游戏时间。

## 2. 十种可长期经营、可相互转型的生涯

| ID／生涯循环 | 玩家决策与主要收益 | 必付代价、敌方反制与失败后果 | 下一条人生路 |
|---|---|---|---|
| **CAREER-01 海商**：买货、探价、配舱、交货、再投资 | 选已签订单还是高风险现货，直航还是绕行；赚真实差价、建立客商信用与仓栈 | 压货占本金，易腐货损耗，税费、工资、护航费吃利润；竞争船队抢先到港可使价格回落。失败可卖存货、接运费单，不以一次赔本终局 | 自建护航队、经营转口港，或为军队承运 |
| **CAREER-02 护镖船长**：议约、验船、编队、护送、交接 | 选保全多少货、何时脱离、救落水者还是追回货；获得运费、履约分红、船员信任 | 须留护卫与救艇舱位，追击过远会丢主队；海盗分兵、诱追、夜袭。按抵达船货分段结算，失船承担合同内责任，不因一箱货全损失所有报酬 | 受商团长期聘用、转赏金猎人、组建独立护航行 |
| **CAREER-03 海盗劫掠者**：买线报、跟踪、截停、夺货、销赃 | 选高值轻货还是急需军粮，恐吓索货还是冒险接舷；获得货、俘获舰与威慑 | 销赃折价、赃物追索、伤员与抢船船员成本；商船联航、诱饵护航、换线，港口提高检查。落败可弃货逃生，但通缉与受害者关系保留 | 成海盗首领、接受有条件招安，或赔偿后转灰色运输 |
| **CAREER-04 赏金猎人**：验榜、找证、追踪、拘捕、交付 | 选抓活首领、查巢穴或追回赃货；获得赏金、线人网络及特定势力准入 | 情报过期、目标换船、同伴设伏；拘捕资格依管辖地和目标而定。抓错人须释放、赔偿并面对当地追究；击沉船而无身份凭证不能自动领首领赏金 | 带队清剿、当海防承包者，也可因越权变成通缉者 |
| **CAREER-05 势力水师／王朝军舰船长**：受命、整备、侦察、会战、述功 | 选战线职责、预备队与救援分工；获得军饷、军需、舰队指挥权与军功 | 任务有目标、时限和军纪，军舰有归属；上级争资源、敌军断粮断缆。撤退保船可保留实力却丢目标；擅卖公船按相应势力法律处理 | 晋为分舰队主将、退役自营，或带明确代价叛离 |
| **CAREER-06 登陆与夺港指挥者**：探岸、运兵、夺登陆点、破岸防、接管 | 选突袭仓库、拆障开港、夺岛驻留或围困谈降；获得港务权、驻地与战略航道 | 需运输、工兵、补给与撤离船；守军阻滩、反登陆、切水源，居民与商户会迁离。占旗不等于有收入，守不住可撤离带走幸存队伍 | 经营海防据点、交港换赏，或成为有领地的海盗首领 |
| **CAREER-07 破封锁与灰色运输者**：验委托、找窗口、装载、穿线、秘密交付 | 选救济粮、军需或禁运高价货，谈通行还是小船分运；收益来自风险运费与短缺需求 | 货物在不同港口法律状态不同；检查、封港、内应失约。失败可缴货换放行、弃货或被扣船；救济动机不自动消除当地违禁记录 | 建灰色商路、转合法保供商，或与封锁方决裂 |
| **CAREER-08 打捞与海上救援者**：查险情、带潜具／救艇、救人拖船、验权结算 | 先救人还是保全货、拖一艘重船还是多接小艇；获得救助费、维修订单、航路消息和信任 | 风浪、余火、吃水与拖航速度限制；原船主、保险方或劫掠者可能争所有权。救人不自动取得其船货；无主认定失败需返还，救援成本可能高于报酬 | 经营修船站、成为护航伙伴、组建搜救船队 |
| **CAREER-09 船坞与舰队承包者**：订材、聘匠、排坞、试航、交船 | 接快速维修、特殊改装还是新舰；收益是加工利润、工匠关系与稳定军商订单 | 船坞占用、材料短缺、返工与质保；敌方劫材料、挖走工匠，客户延付。违约可分期交付或赔偿，不会凭菜单无中生有造舰 | 造自家商队、供应一方战争、迁工匠创设新基地 |
| **CAREER-10 海盗首领／海上盟主**：分利、定规、控据点、派舰、守盟 | 选收费保护商路、有限劫掠、敌对夺港或向势力纳贡；收益是持续航路收入、舰队影响与自治 | 要分赃、发饷、买粮、压纠纷；独吞战利品导致离队，重税逼走商船；水师清剿、商团改线、部将另立。丢主岛后仍可带忠诚小队漂泊，盟主资格需重新取得 | 受抚为海防势力、转港口领主、解盟退休或夺回旧岛 |

这些循环可同时兼营，但人船时间互相竞争：同一艘舰不能离港护航又在坞改装，同一商队不能同时享受互相敌对的排他护送。生涯转型不清零履历；“海盗救过我”与“海盗抢过我”可以同时成立。

转型门槛要能行动解决：海商当猎人需拘捕委托与识别训练；海盗受抚需列明赦免范围、交还公船、处理赔偿和部将异议；退役军官须交还公产或买断；夺岛者要给水、粮、工匠和居民留下生活空间。不能支付一笔钱便清除所有债务、仇怨与证据。

## 3. 八类势力：利益不同，法律也不同

以下是**可生成具体组织的设计类型**，不是对 1650 年具体政权、公司、港口主权的史实断言。真实名称、控制范围、许可、战争关系须另做年代校核；虚构支队、商社、首领要明确标为原创。国家／大组织负责外交，辖港和地方头目仍有可见差异。

| ID／类型 | 想要什么、玩家能换到什么 | 玩家代价与对方反制／失败后果 |
|---|---|---|
| **FAC-01 王朝海防与正规水师** | 要港口安全、军粮与战果；可给编制、公船、合法追捕委托 | 接受军令、港务检查和公产规则；违令扣赏、停补给，叛离被追索；靠援救友舰可保人情，不能自动抹军纪案 |
| **FAC-02 地方守港与岛镇武装** | 要本港粮水、税收和岸防；可给浅港停泊、乡导与驻点 | 本港优先，跨港授权有限；欠粮失信会封仓，夺港后若不给居民保供，守军与商户都可能离散 |
| **FAC-03 跨港海商与船主联盟** | 要可预期航期和损耗；可给货源、合船、信用与护航合同 | 违约提高保证金，抢成员货会被断供；联盟会换航线、集资雇猎人，不能无限给海盗当提款机 |
| **FAC-04 工匠、船坞与军需作坊网络** | 要稳定材料、工资和安全；可给修造、特色舰具、熟练团队 | 排队、预付款与技术适配是成本；强征或拖欠使匠人逃散、工期变长，抢到图样也不能替代熟练工 |
| **FAC-05 海外港务与特许商站** | 要入港秩序、贸易份额与本地伙伴；可给远航货源、补给和新航路 | 具体国家／公司分别建实例，不合成“外国势力”；准入、税货与条约各异，私下合约不能覆盖当地禁令 |
| **FAC-06 岛民、渔户与领航社群** | 要渔场、水源与亲人安全；可给淡水、避风泊处、海况与浅水向导 | 保护承诺需兑现；反复掠夺会使向导藏匿、补给断绝或求助外军，不能把居民只当征税人口 |
| **FAC-07 独立海盗团与盟旗** | 要战利品、泊地、分配公道和活路；可给战斗伙伴、黑市与隐蔽航道 | 盟约不等于绝对忠诚；欺分赃、擅抢盟友客商会引发离队与争旗，部将会权衡独立后的粮饷与风险 |
| **FAC-08 经纪、镖行与追索同行** | 要可靠证据、履约佣金与人员声誉；可给线索、仲裁和共同承运 | 证据造假会失去同行信任；经纪无权替国家赦罪，猎人越境可能成为被追索方 |

每个港分别显示：实际控制者、执法者、可用商会、维修能力、通行限制与最近核实时间。政权争夺时，不把一个好感值同时当通关证、贸易许可和驻军权；拿到商人引荐可能进市集，仍进不了军港船坞。

## 4. 航区、港口与可理解的地理差异

地理先改变决策，再改变美术。下表是可重复使用的航区模板；具体地名与海况另核，不据模板断言所有真实海岸都如此。

| ID／航区模板 | 港口与航路用途、玩家收益 | 代价、反制与失败出口 |
|---|---|---|
| **SEA-01 河口浅湾** | 小港、粮仓与河海转运；小吃水船送货、诱敌分流，夺渡点可改补给线 | 大舰候潮或换驳船，轻艇怕岸射；入口被堵可走支汊或卸货，需付搬运与时间 |
| **SEA-02 岛链狭口** | 哨站、伏击点、避风湾；护航分队和传令艇能发挥作用 | 封一口未必封全海，侦察发现绕路会削弱收费；被夹击可弃据点撤到外岛 |
| **SEA-03 开阔沿海** | 成队商路与大港往来；远程观察、编队保护和耐航有价值 | 暴露时间长、追击易耗补给；迷航或伤舰需拖航、求援或转近港，不能靠退出战斗瞬回家 |
| **SEA-04 风浪外海** | 稀缺远运货与高运费航段；耐航、储水与天气窗口可换利润 | 高楼、重载、损帆各有风险；天气不是固定惩罚骰，出发前给可读预报与不确定性，可等待、改道或中止 |
| **SEA-05 军港与炮台海面** | 军需订单、修造能力与政治目标；夺外锚地可为登陆开路 | 岸海协同、巡逻与检查更强；正面攻不下可转断供、劝降或限时突袭，撤退损失计入战役 |
| **SEA-06 自由锚地与偏远补给岛** | 中转、修补、情报、有限赃货市场；适合海盗与失势船长恢复 | 物资少、买家资金有限，位置泄露招来追捕；搬家需带走仓货与人口，留守队也会消耗食水 |

港口再叠加“产地港、消费大港、转口港、军港、船坞港、隐蔽锚地”中的一至两种职能。没有全服务港：便宜粮港可能无大修船坞，军港擅长整备却不收来历不明的整船，黑市可销小批赃货却不能吞下无限丝货。

## 5. 货物、军需与船匠是同一个经济

港口有实际库存、产能、需求与买方资金。每天按游戏时间补充生产并扣除消费；生产受材料、工匠、设施和安全影响，不能在玩家开关商店时刷新。远处港口可批量结算，但生成的护航、被劫与抵达事件必须对应同一批货和同一艘关键船。

| ID／货物链 | 产出、消耗与玩家选择 | 利益、代价及可被反制之处 |
|---|---|---|
| **ECON-01 食水与粮秣** | 农渔产地供城镇、舰队、岛寨；选便宜大批粮还是占舱少的高值货 | 粮价受消费与损耗影响，驻军越多耗粮越快；截粮可逼敌退却，也会伤居民并失去本地信任，走私保供会破封锁 |
| **ECON-02 木材与修补料** | 产材地、贸易输入供船坞与工程队；选常备修补料还是多装贸易货 | 战损带来需求但可用船坞工位有限；囤木会占仓与资金，敌方可寻找替代产地；关键船材还须加工、适配，不能买木立即造大战舰 |
| **ECON-03 绳索、帆布与桨具** | 纤维、织造与木作供航行及人力推进维护；选备帆备索或减少负载 | 风灾、追击、断缆战术产生维修需求；断一条供应线可拖慢出航，别港替代料能应急但有工期或性能取舍 |
| **ECON-04 铁件与舰具** | 冶作及加工供锚、连接件、兵器和专用器械；选通用件还是定制件 | 通用件易买，特色机关须对应匠师与安装位；拆敌舰可回收但损耗且要验材，不能每次修理增殖铁料 |
| **ECON-05 箭矢、投射物与火器弹药** | 对应作坊生产，依舰具兼容性供部队；选射击储备还是登船人手与口粮 | 存放、受潮、搬运与战斗消耗有成本；不能让所有中国古代器械共用一种无限弹药；供应短缺迫使改战术或停火 |
| **ECON-06 火攻、灭火与救援物资** | 经研究确认的器材另列供应类目；选火攻改装、灭火储备、救艇与拖具 | 改装占船、工时与仓位，撤离艇占人手；火攻被牵引或风流变化可失败，灭火和回收消耗也要补充；不提供现实配方 |
| **ECON-07 药材、衣具与人员照护** | 港口生产／输入供伤员与长期航行；选多带救治物资还是轻装 | 救治耗钱和时间，但保留熟练水手、降低伤员离队；抢药可能招来居民抵制，治疗不能即时复活已确认阵亡者 |
| **ECON-08 织物、瓷货与地域特产** | 不同产地进入消费与转口市场；选稳订单、分港销售还是赌紧缺 | 提供贸易差价与关系礼物；批量卖出会压价，消费能力耗尽就无买家，赃货另受追索与销路约束 |

《武经总要》特色必须能从港口一路带到战场：研究册候选中的楼船、斗舰、蒙冲、走舸、游艇、海鹘与火攻改装，各自需要合适船坞、船员分工和后勤；旗鼓传令、弩石支援、遮蔽接敌、夺缆开路等战术要对应可购买、修复、训练和失去的能力。上述对应关系是原创组合，不声称每个名称在各年代都有统一外形或配置。

船匠提供的是“理解船体并完成改装的团队”。玩家从书册取得知识线索，找匠师评估船体，采购材料、安排坞期、训练操作者、试航后取得能力；不能捡到书即跨时代一键升级。小型快艇、传令艇和救艇有独立岗位，不被最大火炮战舰彻底替代。图样交易只解锁方案知识，工匠、兼容位置、材料和训练仍是条件。

**示例因果链（原创事件）**：岛链铁件船被劫，船坞延后交舰，水师减少护航，商会提高运费并悬赏。玩家可追回铁件拿赏、绕路运替代料赚钱、护送匠人换长期合同，或继续劫粮逼驻岛撤军。各路竞争同一段航期；追回与替代货都抵达时价格回落，迟到者不会仍按“永远短缺”卖天价。

**价格与净收益**：报价由当前库存相对消费、已知来货、风险、质量、合法状态和港费组成，并显示主要原因；同批多买逐步提价、多卖逐步压价。预计净收益必须扣进价、税费、工资、食水、维修、护航／佣金、损耗和资金占用。准确公式与参数留待实验，不以“动态经济”一词代替规则。

**封锁须可维持、可突破**：封锁方分配舰队守航口并支付日常补给，侦察和机动不足会放过小船；被封方可用库存、配给、陆路、走私、外交或突围应对。断供先影响价格和产能，再影响可出航舰数；居民困苦有独立后果，不把饥饿直接变成可无成本收取的胜利分。

## 6. 战后处置决定下一趟能否出航

| 事项 | 玩家选择／收益 | 代价、反制与失败后果 |
|---|---|---|
| 俘获船只 | 分派接收船员、拖回、拆料、按委托返还或申请战利品裁定 | 船主、雇主与控制港可能有不同主张；打赢只取得控制，不自动取得无争议产权。接收分薄本队，拖带变慢，原船员可能反抗；违约吞公船触发追索 |
| 战俘与被救船员 | 按身份选择释放、交换、交有权机关、依法商议赎回；自愿且通过观察期者可招募 | 食水、看守与伤员照护占资源；不得用“重复捕获同一首领”造赏金。虐待降低相关群体信任并引发报复；拒降与已投降者的处置在记录中分开 |
| 船货与证据 | 清点、封存、交失主、合法处置或冒险销赃；抢救货要权衡救人窗口 | 货单、船记、见证与来源链影响索赔；换旗、分箱、转卖不能抹掉已知身份，无法确认来源的货仍有风险，不能自动判所有买者有罪 |
| 修理与损管 | 海上临修保住漂浮与返航，港内大修恢复结构；选修旗舰还是让全队最低可航 | 临修不等同全修，拆船救料减少未来舰数；船坞、工匠和材料排队。长时间不修的失效风险须预告，不突然掷骰沉船 |
| 救援与撤离 | 留艇接人、拖友舰、先救敌船伤员或只保本队；保留人才、口碑与将来证人 | 救艇占舰位，救援暴露于追击；撤离优先级须战前可设、战中可改。救敌人可能改善关系，也可能让其日后回归敌队，不强制换忠诚 |

军舰、公款购买舰、借来的商船、战利品与本人购船须标明所有者；个人盈利、舰队公账和雇主财产分开。战利品分配在出航前可议，归港后不能由玩家暗改规则吞掉伙伴份额。

## 7. 海盗据点与舰队经营

人员与任命细则分别见[船员职业与船上生活](crew-professions-and-shipboard-life.md)和[英雄与同伴](heroes-and-companions.md)。客栈招来的好汉可以同行、成为舰长或独立经营；普通骨干也能成长任职。派出真实人员会减少原船岗位能力，借船、自有船与合伙财产分别清算。自主经营服从本篇市场、工资、库存、名声与榜单规则，不增加另一套定时收益来源。

据点有五项可见约束：泊位、粮水、修造、民心／安全、隐蔽程度。选址靠商路方便劫掠也容易被报知；偏岛安全却依赖运粮。扩泊位、建仓、招匠与修瞭望各有材料和工期；不是攒够一次建造费便永久无成本获利。

每艘分舰队指定船长、任务、可接受损失、撤回条件和补给预算；“袭商”“护路收费”“侦察”“运粮”“巡岛”收益不同。船长按能力、关系和分利选择执行、请求改令或退出。离屏结算要给航路、遭遇、损耗和去向，不把派遣按钮做成定时领钱。

收费保护必须保护：预先约定航段、期限与赔付；同盟海盗若抢已付费船，首领须追回、赔付、惩戒部下或承认违约。强收过高会让商船绕行、联合护航或请水师清剿；破坏港市会缩小销赃和税收来源，恐惧无法替代长期供给。

盟主地位来自船长支持、分配履约和共同安全。可用议盟、共同远征、支援落难船长扩大舰队，也可胁迫兼并，但必须留下驻守成本与反叛风险。反制是分化盟友、断军需、夺外围泊地；失败后允许带忠诚舰队撤至次级基地，旧部与旧债继续存在。

## 8. 名声、好感、犯罪与悬赏分别记录

| ID／维度 | 如何产生、玩家能换到什么 | 代价、传播与反作用 |
|---|---|---|
| **REP-01 知名度** | 被可靠记录的大航行、大胜、救援、劫掠；让委托人知道玩家 | 只表示被认识，不代表受敬重或有罪；更容易被认出、跟踪和针对，消息随船信传播 |
| **REP-02 履约信用** | 按约交货、支付分利、如实清算；降低保证金、获得大单 | 违约按可控责任与救援证据区分；信用要靠多个独立履约建立，自己给自己开单无效 |
| **REP-03 海战威望** | 完成有难度的战术目标、对有实力敌手保全队伍；获得指挥邀请 | 靠欺负弱船刷不出等价威望；惨胜有损失记录，击沉己方或无关船不能折为军功 |
| **REP-04 威慑与恶名** | 被证实的夺船、报复与胁迫；可能促使目标交货或避战 | 会促成护航、追捕和贸易排斥；救人可改变个人关系，但不删除已证侵害 |
| **REP-05 仁义与救助口碑** | 可核实的救人、释放、保供与遵守投降约定；获得向导、照护和支持 | 有真正时间与资源代价；先制造灾祸再救援不赚同等口碑，受害群体仍保留原记录 |
| **REP-06 船队内部威信** | 发饷分利、共同承担风险、照顾伤员；稳定部将与熟练水手 | 对外排名高也可能欠薪而失队；滥权、偏袒和弃援引发离队，不能靠买礼物一次归零 |

此外分别保存**各势力关系、各辖区法律状态、各发布者悬赏**。法律可为“准入／受限／调查／通缉／交战俘获对象”等不同原因，不能合成从善到恶的一条轴。敌国依法交战的军官不因此在所有港都是海盗；某港被赦免不代表受害商会撤回民事追索。

法律变化要有事件、证据、适用范围与获知过程。换旗可影响远距离识别，不能改写本人身份；一次误认有申诉、证人、赔偿或谈判路径。悬赏数字由具体委托能力与目标价值决定，绝不直接等于知名度或世界排名。

## 9. 赏金从发布到结算

| 阶段 | 玩家决策、可得利益 | 成本、反制与失败处理 |
|---|---|---|
| 发布 | 官署、商会、船主或玩家发布追回货、抓捕、查巢、护送证人等明确目标；玩家发布能弥补自身无暇追击 | 发布人需有资金／承诺额度、管辖资格与明确完成条件；私人悬赏不赋予越境执法权，违法委托可被当地追究；超支不生成无资金奖励 |
| 接单 | 查看是否独占、有效期、可否转包、活捉条件、交付港、保证金与争议条款 | 多人可追时提前显示竞争；接单不锁死目标，目标继续行动；取消按契约处理，不让换港重新生成同一份奖金 |
| 找人 | 买目击、访船工、查货流、观察航迹；新鲜可靠消息可缩短搜索 | 每条线索有观察时间、来源可信度和可能范围；目标可换船换泊地、泄露假路线。过期情报保留“最后所知”，不画成当前位置 |
| 执行 | 跟踪确认身份，选择拘捕、谈判交货或摧毁被授权目标 | 战场有逃脱、伪旗、替身和误伤；悬赏不是对所有同行人员的无限攻击许可；目标转属新势力后先显示合同是否仍有效 |
| 举证 | 交本人、可核验身份物、船货清单或独立见证，按目标种类组合要求 | 击沉剪影、捡旗或口述不能单独证明首领死亡；证据可损毁，支持补证、部分支付或拒付；反复上交同一凭据无效 |
| 结算 | 发布方检验证据、查共同参与约定，支付奖金并更新目标状态 | 目标、案件与奖励有唯一记录；参与者分同一奖金池。活捉后逃脱是原案后续，不自动刷新满额赏金；真正新罪行可形成新案，但须另有受害与资金 |

玩家成为被悬赏者时，可以谈判赔偿、申诉误认、履行赦免条件、找保护人、转移航区或迎战猎人；每条路有成本。缴保证金仅暂停明确案件的部分追捕，不抹除其他发布者的赏单；击败追兵会改变追捕预算与手段，不能永久清空“世界警察”。

## 10. 防重复刷取与自买自卖：世界规则先自洽

| 漏洞诱因 | 玩家仍可做的合理决策 | 约束、收益边界与失败后果 |
|---|---|---|
| 自己发布、自己或部下领赏 | 追自己真实丢失的货、向独立受害人提供服务 | 关联主体同账核算，只转移原有钱，不增发奖金、信用或榜分；捏造受害事件拒付并留失信记录 |
| 同港买卖、两自有港循环倒货 | 合理储货、转运、加工后出售 | 买卖价差、费用和有限外部需求存在；内部调拨不算销售利润，只有最终独立买家支付与真实增值才计商业成就 |
| 抢自己的商船、放俘再抓 | 安排训练、演习、真实内部叛变剧情 | 演习明确不计战果；相同船货和目标保留来源，重复回收不增殖资产；真实叛变须实际脱离和损失，不能玩家切旗即刷 |
| 先制造短缺再吃无限溢价 | 允许垄断、投机与战争经济，作为有代价的玩法 | 有库存上限、替代供给、买家资金、仓储损耗与关系代价；操纵可盈利但有限，诱发改线与查办，不能永远同价收购 |
| 救自己击沉的人、反复借难民刷善名 | 仍允许救回受害者并补偿 | 同一事件将伤害与救助分别记录，补救减少损失而非净造巨量善名；共同制造事故的关联船不算独立见证 |
| 读档、重复交接、离屏刷新 | 单机允许存读档尝试其他选择 | 奖励绑定存档内已完成事件；恢复同一状态不重复支付，读档不受道德惩罚。无联机反作弊承诺，也不以处罚玩家替代状态正确性 |

保险、借贷、赎回如后续加入，必须绑定实际所有权、可证明损失、责任范围与抵押；不能“卖船后再报损”、对同一损失向多个机构重复取全额赔偿。债务上限与展期事先可见，不靠无限复利把玩家锁死。

## 11. 世界榜单：玩家与 NPC 的共同海上世界

**默认单机**。世界榜指本存档已建模海域里的玩家与具名 NPC 船长、商号和舰队，不假设联机，也不把全球玩家排行榜、赛季运营或联网反作弊塞进基础方案。NPC 同样付粮饷、占用船坞、损失船只、争取合同与承受法律结果；不能无成本补舰只为压玩家名次。

| 榜单 ID | 比较对象与计分依据 | 决策、收益、代价与防偏差 |
|---|---|---|
| **WORLD-BOARD-01 舰队实力榜** | 舰队；可用舰艇、熟练人员、补给与实际可指挥程度 | 鼓励养得起的有效舰队，带来威慑和目标风险；待修空壳、借用公船不能重复算给数位船长，实力高不等于犯罪高 |
| **WORLD-BOARD-02 海上功业榜** | 船长；独立有难度目标的完成、战果与保全表现 | 鼓励破封锁、护航与夺港等不同战绩，带来邀请；欺弱、重复攻同一废弃据点不等价计分，惨胜注明损失 |
| **WORLD-BOARD-03 商业成就榜** | 商号；独立贸易净收益、履约与持续供给 | 鼓励经营，带来信用机会和竞争；按真实成本与外部交易计，公款、赎金、搬运自有资产不混作贸易利润 |
| **WORLD-BOARD-04 江海声名榜** | 船长；已传播的重大事件与覆盖范围 | 反映“大家谈论谁”，带来委托也暴露行踪；显示声名来源，不把救援者与恶名海盗排成一条道德高低线 |
| **WORLD-BOARD-05 追索悬赏榜** | 案件目标；各发布者当前有效可支付金额 | 高额吸引猎人，显示发布者、案由、地域和时效；多案可汇总展示但逐案结算，不把撤销／已付赏金继续累加 |
| **WORLD-BOARD-06 海路守护榜** | 船长／组织；真实护送、救援、保供与受益范围 | 鼓励非掠夺成就，带来居民支持；同一事件、关联自救不重复加分，护路不能用先抢后还刷人数 |
| **WORLD-BOARD-07 猎首功绩榜** | 猎人／团队；已核实且已结案的独立追索、目标难度、活捉或追回目标完成度 | 带来可靠委托与同行合作；只计有实际授权和独立受害人的任务，重复抓放、关联赏单不增功绩，不单按收款总额排序 |
| **WORLD-BOARD-08 海盗盟旗榜** | 海盗首领／盟团；可维持的盟船、支持船长、实际控制航路与可用据点 | 带来议盟资格、挑战者与围剿压力；一艘盟船只归属一个当前盟旗，恐吓声量和悬赏不等于统治力，部将离队与供给崩溃会真实降低名次 |

不设把财富、杀敌、悬赏简单相加的唯一“天下第一”。玩家可把一项选作长期目标，传记记录兼营成就。榜单逐期更新、保留升降原因与挑战者；公众版注明最近报信时间和可信区间，过期信息不冒充实时全知。结算视图若展示精确统计须明确是游戏记录，不把秘密据点位置泄露到海图。

每个具名竞争者有目标、惯用船队、商路、盟友和失败记录。击败当前第一可改变航路控制与故事机会，却不自动得到对方全部声望；失去名次也不撤销玩家操作权。玩家可救竞争者、合作破封锁或争同一订单，排行榜应产生遭遇，而不只是菜单里的数字。

## 12. 输了仍有航程，成功也有新难题

| 损失 | 可继续的选择与收益 | 必须留下的代价／防止故意破产获利 |
|---|---|---|
| 船货丢失、还有人 | 做短途雇员、借用受限小艇、接救援或低风险运输，恢复现金流 | 救济／租艇不能出售抵押，不给比旧家底更多的净资产；工资债、失约与装备损失仍需处理 |
| 旗舰被俘、人被扣押 | 谈赎、交换、受限服役、盟友援救或越狱；保留人际与已知航路 | 各路线耗时间、关系、财物或法律风险；越狱不自动带回原舰，重复自投不能复制赎金 |
| 岛寨失守、舰队分裂 | 带残队撤退、投靠保护人、暂当雇佣船长，再争回基地 | 仓货和建设可能丢失，部将各自行动；老居民是否支持取决于此前关系，不自动全员回归 |
| 商业破产、被拒贷 | 清算部分资产、展期、受雇承运、合伙让股；重建信用 | 不无限复利；清算损失与具体违约保留；不能靠破产取消已转给自己的资产追索 |
| 主要势力通缉 | 去仍可停靠的中立／灰色港、申诉、赔偿或隐蔽经营 | 世界必须保留至少一条有成本的恢复路；不会所有港同时因单一恶名值封死，也不会任意瞬间赦免 |

默认不因普通海战失败永久删档；死亡／家业继承只作为另行确认的高风险模式或明确剧情节点。恢复任务必须能完成，不把最弱船长重新丢进同级追兵循环。玩家可选择退出当前事业、退休记传，或继续冲击另一项成就，不被强迫一直做最赚钱的职业。

## 13. 四条可验证的完整人生与下一阶段边界

1. **小商到海防商主**：厦门承运粮货，雇护航后发现修船缺索，转运绳索换船坞关系，救下遇袭镖船，联合商户维持一条航路。收益是信用与商路，代价是军需合同挤掉现货生意；战争升级后可退约赔钱或承担征用风险。
2. **散盗到海上盟主**：劫小批高值货求第一艘快船，以释放俘虏换向导，联两位船长夺偏岛，控制分利与粮水，再决定收护航费还是继续袭商。水师围剿迫使他带残队撤离；卷土重来依赖旧盟友，不靠自动刷新满编舰队。
3. **猎人到失势军官**：追索海盗首领得到活捉委托，发现目标获敌对港保护，选择外交引渡或违法越境；参军后参与破封锁与登陆，因保人撤退失去军职，却带着海战本领和救援口碑转当护航船长。
4. **船匠合伙人到攻港统帅**：护送工匠、经营修船队，以《武经总要》灵感改装与混编取得独特能力；接军需订单换指挥机会，以传令、接应、夺岸点完成攻港。若港口停产，必须先保供、修坞和招工，军事胜利才可能成为长期收益。

最低接受场景：十种生涯各完整出航结算一次；同一人“商会信任／官府通缉／船员拥护”可并存；封锁被绕开后供需恢复；同批货、同一首领、同一沉船证据重复交付不增发奖励；自买自卖不造利润或榜分；旧情报不锁定目标当前位置；俘船须配人才能拖回；匠师与军需中断会影响改装；攻港后无粮无工不自动产税；NPC 会经营、失败和恢复；三个不同阶段破产均有可执行后路。以上全部**未测**，文档覆盖不代表可玩性、平衡、存档正确性、GPU 或性能验收。
