# 连读后的补充核验

2026-10-24，主编在独立审读发现因果和时代背景薄弱后补查。以下不是新增历史发现；未核原刊、原信或日文禁令原件。

1. **1630接子与教育来源。** 平户郑成功纪念馆的生平和年表、以及本轮SOURCES-LATE L03—04所列《台湾外纪》卷03，支持1630赴福建和后来的士人教育。第三部第四章应引用这两种外部资料，不能以本项目DESIGN充当史料。私人初见与改称的具体过程仍是重建。[纪念馆](https://teiseikokinenkan.com/en/about)
2. **弘光授郑芝龙南安伯应置于1645春。** 《明季南略》卷11“杀鲁王使陈谦”回述乙酉春陈谦奉弘光诏封芝龙南安伯；故第五部第三章可从1644南京延伸到1645春，不能将封爵现场固定在1644。误写“安南”的笑谈不采作确证。[原书电子录文](https://zh.wikisource.org/zh/明季南略/卷11)
3. **陈谦线提供官府信用失灵的实际冲突。** 同条记陈谦奉鲁王使，与芝龙有旧，郑招其来；因函中称皇叔父、不称陛下遭隆武拘系。郑救而未果，夜间转地处死，郑哭葬。是后出史家叙述，非保存的逐时狱案；信使来回、郑的语言及家族人物争执都须标文学重建。不能据这一条把郑后来撤防归结为已证实的单一报复动机。[同卷](https://zh.wikisource.org/zh/明季南略/卷11)
4. **隆武必须在正文有明确结局。** 同卷“隆武奔赣”“隆武遇害”写行在败走、汀州遭追、福州遇害，其他记载仍有细节分歧。本作只收束1646兵败遇害，不重演确日、凶手、死法或锁定死地。父子得知消息的先后和反应为创作。[同卷](https://zh.wikisource.org/zh/明季南略/卷11)
5. **日本不是抽象的另一岸。** 哥伦比亚大学所收1635幕府命令英译，面向长崎奉行，涉及日本人出海、海外归人和禁教；本轮读的是David J. Lu文献选编的教学节录，不是日文原件。出岛官方年表亦记1635唐船限长崎、日本人出入境禁止，1639葡萄牙人被逐，1641荷兰商馆从平户迁出岛。可将这些变化写成寄信、委托接人、找船靠港的实际困难；不能凭一般禁令推定田川氏某次申请的具体拒绝原因或1645获准的文件。[1635命令节录](https://afe.easia.columbia.edu/main_pop/ps/ps_japan-tokugawa-edicts-foreigners.htm)；[出岛官方年表](https://nagasakidejima.jp/english/history/)

这些核验用于修订有问题的现场和连接，不证明全稿没有其他史误，也不代替文学判断。
