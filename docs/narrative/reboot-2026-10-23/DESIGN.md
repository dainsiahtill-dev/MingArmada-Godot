## 六部因果链与分章

### 第一部：出海的人（约1623—1625，4章）

1. **唐船来处**：平户的跨海贸易现场，澳门学话经历作为人物已携带的本事进入行动；李旦网络让一官看到语言如何变成位置。事实E01—02，现场属重建。开篇须有正在争取／赶办的具体事，不能履历介绍。
2. **岸上的人**：平户家庭与赴大员机会；田川氏有自己的生活，1624福松出生不强演为父亲在场见证。离家有真实经济与职业机会，不编亲人被害的转盗动机。承接1的网络与本事，留下跨海家庭的时间差。
3. **大员的舌头**：VOC迁离澎湖后的贸易据点与通译工作。中国货源、明方限制与荷方武力相互制约；台湾已有原住民社会，不写无人土地。语言让他接近利益分配，却不让他决定分配。
4. **空出来的位置**：1625李旦等领袖去世、网络分裂，郑离开荷方雇佣，进入带武装的海上集团。用具体招集、谈份、备船的行动写出这一跨越，重大事实E04—05；首次参与的具体过程标文学重建，不“自动继承全部势力”。

### 第二部：海盗的名字（1626—1628，4章）

1. **破桅归港**：1626漏船归大员，按约分给VOC约960里亚尔；刚成为私掠者的人被维修、部众与外方分成同时索取。由I4的选择直接生出后果。承认劫掠伤害，不把每次行动洗成救人。
2. **谁让鱼船过海**：李国助与VOC的保护费竞争、饥荒与郑部吸纳人众相互推进。历史人物各有利益；不要将李国助做的事移给郑。可跨一段清楚时空，不让主角凭空参加所有会议。
3. **交出一船人**：1627许心素要求荷方交出郑部俘船，VOC保留少数首领。让许的军务／贸易／家庭压力可见，郑面对曾合作一方的交人行为，关系由钱扩展到生死和岸上权力。
4. **城门内外**：天启末至崇祯初攻海澄、中左所及明方将领问责。胜利带来真正可谈招抚的地位，也带来要喂饱的人。拒绝把城无一伤或所有村民欢迎写成定论。

### 第三部：官印与海约（1628—1631，4章）

1. **有条件的官身**：多阶段受抚，以解散胁从、讨捕渠魁等要求塑造选择；他要进入岸上秩序，旧海上力量未必愿意。不要重演无据的囚首仪式。
2. **别人的甲板**：1628登荷船访问受到压力、签三年固定价格供货约；限制未来的商路成为IV的根。具体强制方式未核，不编铁链拘禁为事实。
3. **白旗三个黑点**：1630借荷舰和钟斌攻李魁奇；李曾反过来逼走郑，清楚交代逆转。联军相互辨认与夹攻构成完整动作场；战后庆功缺席的钟斌种下下一层威胁。可适度时间过渡，勿把多日写成同日。
4. **来家的孩子**：1630福松赴明、教育与父亲身份变化；贸易协作仍不能保证一切顺从，钟斌拥众及1631荷方扣商船使利益冲突扩张。让家庭相见完整成戏，政治消息进入生活而非吞没它。

### 第四部：合作者开了炮（1632—1633，4章）

1. **八张通行许可**：荷方想绕过郑获得大陆贸易自由，郑能争取的许可与明方权力有限。普特曼斯向巴达维亚递方案、刘香／李国助关系逐渐进入视野。采用可核资料，八张若使用应说其为信中说法，并非所有港口通行凭证。
2. **来船没有回礼**：1633夏厦门突然受袭，港内人仍按贸易往来理解来舰；郑本人是否现场不明，从守港者或普特曼斯视点写，不编他站岸目睹每条新舰焚毁。
3. **信比船先到**：郑重建力量、截信伪答（有学术转述，注层次），荷方还误扣船以联合刘香、李国助；双方受真实天气与通信迟延限制。无需郑精确预报风暴，不把对手写蠢。
4. **料罗湾**：火攻、接近与包围的可证轮廓，海面空间及每一步行动清楚；远景—近身—逃脱／胜负自然切换，不钉未核编制。胜利结算到贸易条件，不能写荷兰人从此永远臣服。

### 第五部：海面归于一姓（1635—1644，3章）

1. **刘香的最后一程**：荷方不再重结盟、刘陷孤立，1635败亡；芝虎的损失在行动后果与未归消息中呈现，不拍定有争议的死法，避免无据遗言。
2. **银流向岸上**：晚1630年代的贸易、产业、亲族、军职和日本往来变化。胜利使他可以安顿家门，也让越来越多人的饭碗系在他的决定上；田川氏仍在日本，别写到处随军。用一场完整的生活／贸易事件表现规模，不列财富数字。
3. **北京之外**：1644消息、南京仍有明廷、郑森求学与弘光封爵。父亲的海上事业第一次必须面对不能靠一场海战解决的权力更替，鸿逵等有自主行动。

### 第六部：福建的皇帝（1645—1646，3章）

1. **迎来的朝廷**：隆武拥立联盟、军饷与郑氏权力，黄道周等有自己的目标；同年田川氏赴闽，母子重逢与政局进入家门交织。两书对芝龙拥立初态相反，作者不得假称唯一实录。
2. **海上的钱，山里的兵**：缺饷、催征、出师、撤防和多路清军进逼。把海贸现金、家产与战地补给的落差写成行动，同时保留他实际选择与责任；不写一关亡国的简图。
3. **留在海上的船**：1646政治交涉、父子各择道路、赴福州受控北上。多方判断均只能依据当时所知；不复述史书传奇长对白，不编全家轮番拒绝的家庭审判。正文止于可确定的命运转折，极短后记交代1661及田川氏死年／死法异说。
