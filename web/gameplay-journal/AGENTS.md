# 玩法长卷维护

继承根AGENTS。此目录为游戏介绍网页，属于独立静态前端，不是正式Godot算法。

- 每次游戏项目有新进展，同步content、航志与必要图片，构建并运行--check。
- 用户最新选择：局域网服务监听0.0.0.0:4173，用户自行维护frp；上游127.0.0.1:4173。保持服务与本目录dist一致，不另部署脱离更新的数据副本。
- `.openai/hosting.json` 登记的是先前创建、尚未部署的owner-private Sites草稿；用户随后选择frp，不自动发布该草稿，不把expected_url当作已上线。
- 不改用户frp、全局防火墙或游戏存档。当前专用TCP4173本地子网规则见README。
- 状态与图片类型必须清楚：生成原画、Blender静态渲染、独立实验、正式游戏界面不能相互冒充。
