# 海上明旗 · 玩法长卷

## Register

brand

## Users and purpose

供玩家与项目所有者持续了解海上明旗的玩法、艺术资产与真实开发进展。以图片和具体选择介绍游戏，区分已可玩、独立实验和规划，不把设计数量当作完成度。

## Direction

沿用项目根 DESIGN.md 的青绿海疆原画、墨青漆木、旧金细线与朱砂。首屏看原画，正文安静阅读，实机图片保留原貌。标题中文宋体/楷体，操作中文无衬线；不用外部字体或CDN。

## Maintenance

每次游戏项目有新进展，同步更新 content/gameplay.json、必要的 content/media.json 与开发航志，运行 scripts/build.mjs 和 --check。新增实机证据才能提升可玩状态。根 AGENTS.md 与 README 记录具体流程。
